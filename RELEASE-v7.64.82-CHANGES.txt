# ตัวติดตั้ง Production v7.64.87

รวมงานทั้งหมดจาก v7.64.81 และงานเพิ่มเติมที่คุยไว้:

1. รายการที่ลูกค้าเลือก: ย้ายกล่องยาวเป็นปุ่มแจ้งเตือนพร้อมจำนวนที่หัวข้อแพคเกจ กดเปิดรายละเอียดแยกวางบิล เงินสด และคู่สัญญา
2. เพิ่มตารางตรวจสอบรายการก่อนกล่องหมายเหตุในหน้าแก้ไข เลือกรับบางรายการได้ และบันทึกผ่านทางเฉพาะที่ใช้สิทธิ์ “ยืนยันรายการที่ลูกค้าเลือก” โดยไม่ต้องมีสิทธิ์แก้ข้อมูลส่วนบุคคลหรือแก้รายการทั่วไป
3. ตรวจราคาและสิทธิ์จากข้อมูลจริง ป้องกันรายการเปลี่ยนระหว่างตรวจ กดซ้ำ และบันทึกเคสที่ส่ง Order/ChargeClose หรือปิดรอบแล้ว บันทึกรายการและประวัติในธุรกรรมเดียวกัน
4. หลังบันทึก อัปเดตสรุป A4 และป้ายรับรายการแล้ว เก็บรายการเดิม แพคเกจหลัก หมายเหตุ และข้อมูลส่วนบุคคล การบันทึกทั่วไปไม่ล้างคำขอที่ลูกค้าส่งมา
5. แก้การเลือกเบราว์เซอร์สร้าง PDF ให้มีตัวสำรอง ใช้ headless mode รุ่นใหม่บน Windows และแจ้งข้อผิดพลาดแบบอ่านง่าย
6. ขยาย QR ลูกค้าจาก 22 เป็น 40 มม. เพิ่มขอบขาวและความคมชัด ใช้รูปแบบเดียวกันใน HTML / PDF / เอกสารพิมพ์
7. ปุ่มพิมพ์ A4 บนหน้าค้นหาลูกค้าเรียกหน้าต่างพิมพ์โดยตรงจากข้อมูลที่บันทึกไว้
8. ภาพสรุปรายการลูกค้าแยกยอดหลัก / รายการเพิ่ม / ยอดรวม / สถานะคนละแถว ดาวน์โหลดแล้วไม่รีโหลดหน้าและไม่ทำให้เซสชันหาย
9. ช่อง Location เหลือขอบกรอกชั้นเดียว และระหว่างบันทึกแสดงกล่องสถานะเดียว
10. บันทึกข้อมูลส่วนบุคคลที่ไม่ได้เปลี่ยน ID จะคงคอลัมน์ ID/Passport เดิม หากเปลี่ยนไปใช้เลขของอีกระเบียนจะแจ้งให้ตรวจสอบข้อมูล โดยไม่รวมลูกค้าอัตโนมัติ

คงงานก่อนหน้า: หน้า EMR/Worklist, หมายเหตุและการนำเข้า, ธีม/สีวางบิล-ชำระเอง, หน้าลูกค้าบนมือถือ, พรีวิวขนาดโทรศัพท์, การอ่านบัตรด้วยกล้อง, ความรู้รายรายการตรวจและนำเข้า TXT/Excel, หลายบริษัท/ปี, เล่มผลตรวจ, โฆษณา/บทความ, ระบบนัด Mobile/Inhouse และปฏิทินลูกค้าจอง

วิธีติดตั้ง: แตก ZIP ทั้งหมด → เปิด INSTALL-REPAIR.vbs → อนุญาต UAC → รอ Complete SUCCESS → เปิดเว็บแล้วกด Ctrl+F5 ตรวจเวอร์ชัน v7.64.87
ห้ามเปิดตัวติดตั้งซ้อนกัน ระบบสำรองและรักษา .env/ข้อมูลเชื่อมต่อและข้อมูลเดิม หาก Update Center เก่ามีปัญหา ใช้ REPAIR-UPDATE-CENTER.vbs หรือติดตั้งตรง

ตรวจสอบ: 77 release tests, TypeScript build, PostgreSQL อัปเกรด v7.64.81→v7.64.87, การรับรายการจริงด้วยบัญชีบริการลูกค้า, การบันทึก ID/Passport, การดาวน์โหลดโดยคงเซสชัน, คำสั่งพิมพ์ตรง, QR จาก HTML/PDF และกลไกสำรอง/ซ่อม updater
ยังไม่ได้ทดสอบ GUI/UAC/VBS/Task Scheduler บน Windows เครื่องจริง หรือกล้อง/เครื่องพิมพ์จริง
