# v7.63.98 Production Windows installer startup hotfix

## Symptom
On Windows, the WPF installer can fail at `ShowDialog()` with a `C:\Users\HI7B18~1.USE` path-not-found message. This is often the launcher/worker working directory becoming an unusable short Windows profile alias. The UI's `ShowDialog()` stack position is not itself the original file-system operation.

## Fixes
- Elevation launcher (`tools/start-production-installer.vbs`) now starts PowerShell from verified `%SystemRoot%`, not the downloaded ZIP's folder.
- GUI worker process starts from the verified, created `%TEMP%\HealthCheck-Production-Installer` directory instead of the downloaded user's profile directory.
- Launch callback validates paths and catches errors locally. It shows an actionable error inside the installer, writes a runtime log and restores the Install button state rather than aborting the entire WPF dialog.
- Top-level GUI now catches unexpected WPF exceptions and offers an `C:\HealthCheckInstaller` extraction fallback.
- The plain PowerShell worker wrapper also uses `%TEMP%` as its working directory.
- Release identity advanced to v7.63.98, no HIS, database or business functionality altered.

## Manual Windows verification still required
Run installer on the originally affected Windows user profile and verify the UAC dialog, installation GUI, Backup/Deploy/Migrate/Start/Health and Update Center on a non-live clone before upgrading Production. Do not claim the 8.3 issue definitively fixed until that environment is retested.
