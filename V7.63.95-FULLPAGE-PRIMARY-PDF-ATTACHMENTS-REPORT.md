# HealthCheckup Smart Search v7.63.95 – Production Only

## Implemented

- Full Page **Edit Company Year** workspace using the current form's exact Corporate letter numbering **00–08**, with direct navigation, two independent panels (edit and PDF management), and footer actions.
- A generated Corporate Circular PDF becomes the **main document** only when explicitly clicking **สร้าง PDF หลัก**. The backend generates it from the *saved* year record and Corporate letter memo, not from a transient browser draft. PDFs are stored as immutable versions in `company_year_primary_pdfs`; newest version is the current main document.
- Existing single-file uploads in `company_year_documents` are **preserved byte-for-byte in their original table**, presented as **legacy attachments** with view and download links. There is no destructive migration and new PDF creation cannot overwrite them.
- New user-uploaded PDFs append into `company_year_attachments` (multiple files supported, 20 MB max per file), with metadata, view/download, and delete action for *new* attachments only. Old imported PDF is deliberately not removable in the new UI.
- Other company/customer PDF view buttons now open the latest generated main PDF when present, otherwise fall back to the former company-year PDF.
- Retained Production Only runtime guard, PostgreSQL runtime, Windows installer and Update Center helper.
- Migrates automatically on application startup with `CREATE TABLE IF NOT EXISTS`, schema version **0211**.

## Test coverage

- JavaScript syntax and 37 static release-integration checks passed.
- Full Page static visual check on Chromium 1680×945 showed the workspace fills the viewport without horizontal overflow when existing `fullpage-unscaled` support is active.
- PDF generation uses existing Corporate Circular PDF template and PDF backend from v7.63.94; PDF rendering was **not** verified against live patient/company data in a Windows Production database.

## Important before deployment

- Back up the PostgreSQL database first. Do not overwrite the old production database during installation.
- New tables require DB permissions for `CREATE TABLE` and `CREATE INDEX`, or must be deployed by DB administrators ahead of time.
- Verify a company/year with legacy PDF on an isolated data copy: it must appear under attachments and remain accessible after generating the main PDF.
- Verify Thai font rendering and the appended document history on Windows Server before Production rollout.
- This package does not claim a live Windows Server end-to-end install test.
