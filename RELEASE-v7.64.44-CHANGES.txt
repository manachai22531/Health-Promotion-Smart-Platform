HealthCheck v7.64.44 — production release
- แก้ปุ่มซ่อนจาก A4: PATCH เฉพาะสถานะรายการ ไม่ส่งข้อมูลทั้งระบบ ไม่ซิงก์รายชื่อทั้งหมดซ้ำ
- ปุ่มตอบสนองทันที แสดงสถานะบันทึกข้างปุ่ม คืนค่าเดิมเมื่อไม่สำเร็จ ป้องกันกดซ้ำ และมี timeout
- ตรวจสิทธิ์ orderItemManage ตรวจค่าก่อนเปลี่ยน ป้องกันแก้ชนกัน เก็บ audit และ revision ใน transaction
- พรีวิว PDF รีเฟรชหลังบันทึกซ่อน/แสดงสำเร็จ โดยไม่บังฟอร์มด้วย global wait overlay
- รวมปุ่มด้านล่างเป็นแถวเดียว แสดงปุ่มพิมพ์ครบ ใช้ชื่อสั้นพร้อม tooltip ของชื่อเดิม
- A4 ใหม่: หัวกรมท่า เส้นทอง ตารางสลับสี เสริมวางบิลสีฟ้า ชำระเองสีเขียว คู่สัญญาสีม่วง ยอดรวมสีกรมท่า
- รายการที่เลือกแสดงแยกสามประเภท ไม่แสดงส่วนสิทธิซ้ำเมื่อเลือกแล้ว และไม่แสดงกล่องหมวดว่าง
- แพ็กเกจคู่สัญญาเลือกผู้รับผิดชอบค่าใช้จ่ายได้: ชำระเอง / วางบิลบริษัท (ข้อมูลเดิมคงเป็นชำระเอง)
- รวมราคาคู่สัญญาเข้าฝั่งที่เลือกเพียงครั้งเดียว พร้อมแสดงผู้รับผิดชอบบน A4 และคงฟิลด์ HIS เดิม
- ห้ามแก้คู่สัญญาหรือผู้รับผิดชอบเมื่อมี Order ที่ยังไม่ยกเลิก ทั้งฝั่งหน้าจอและ API
- ตัวอย่าง 20 รายการพร้อมแพ็กเกจเสริมสามประเภท ยอดรวมและลายเซ็น อยู่ใน A4 หน้าเดียว
- รายการยาวต่อหน้าอัตโนมัติ ไม่ตัดทิ้ง ยังคง native PDF Viewer Toolbar ซูม ดาวน์โหลด และพิมพ์
- คงการยืนยันซ้ำ ไม่สร้าง Visit/EXP ซ้ำ และคงการตั้งค่ารูปแบบการตรวจใน SetUpMaster

ติดตั้ง: Application Update > Upload ZIP > Preflight Only > Install Update
หรือแตก ZIP ลงโฟลเดอร์ใหม่แล้ว Run as administrator ที่ INSTALL-REPAIR.bat
สำรองฐานข้อมูลและ .env ก่อนอัปเดต ตรวจ /api/version เป็น v7.64.44
ไม่มี migration ใหม่ในรุ่นนี้; คง migration 0214 และข้อมูลเดิม
การเลือกผู้รับผิดชอบใช้จัดกลุ่มยอดในโปรแกรม ไม่แก้รหัส PaymentType/Payor ของ HIS อัตโนมัติ
