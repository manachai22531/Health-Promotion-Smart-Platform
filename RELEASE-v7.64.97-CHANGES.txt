1. ปุ่มคัดลอกต่อแถว คัดลอกข้อมูลที่แสดงจากต้นแถวถึง Company/Year คั่นด้วยจุลภาค รวมลำดับ ไม่รวม checkbox/ปุ่มจัดการ ไม่ดึงข้อมูลที่ซ่อนตามสิทธิ์หรือคอลัมน์ที่ผู้ใช้ปิด รองรับ CSV quoting เมื่อข้อความมีจุลภาค/เครื่องหมายคำพูด และ fallback สำหรับ HTTP LAN ที่ไม่มี Clipboard API
2. จัดเครื่องมือรายชื่อลูกค้าเป็นแถบกระชับ แถวค้นหา/ตัวกรอง/คำสั่ง และแถวเลือก/Booking รองรับจอเล็ก
3. ย้ายจัดการมาด้านหน้า ตรึง เลือก/จัดการ/HN/VN ลำดับอยู่ถัดจาก VN และไม่ตรึง ใช้โครงคอลัมน์ร่วมทั้งบริษัทและ Project Booking; แสดงลำดับเสมอและรวมตอนคัดลอก
4. ฟอร์มเพิ่ม/แก้ไขลูกค้าเต็มจอ หัวข้อและบันทึก/ยกเลิกอยู่ประจำที่ เลื่อนเฉพาะฟอร์ม ปรับคอลัมน์ฟอร์มตามขนาดจอ
