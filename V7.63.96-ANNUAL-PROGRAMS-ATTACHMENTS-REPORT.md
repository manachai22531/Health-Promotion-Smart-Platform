# Health Checkup Smart Search v7.63.96 – Production Only

## Changes
- Moved previous PDF upload/list widget into the left **+ เอกสารแนบ** section. The left navigation now scrolls directly to the upload widget. Legacy uploaded PDFs remain in their original PostgreSQL table; new attachments still append into the v7.63.95 multi-file table.
- Right panel is limited to **generated main PDF**, its history and preview. Main PDF generation remains separate from uploads.
- Section 04 now puts **โปรแกรมที่โรงพยาบาล** and **โปรแกรมครอบครัว** first. Both have HIS package search, price lookup, quantity, total and add/remove rows, with the saved program list used in the letter PDF.
- Existing **วางบิล** and **เงินสด** rows remain below and continue to manage yearly billable and cash items independently. Old HIS selections already saved in the PDF memo are retained; previous auto-classified annual package rows are imported into document program rows only when a year has no saved circular memo.
- Extended JSONB program entries with `quantity` and `unitPrice`, backward compatible with the original 3-column program fields. PDF renderer still uses the saved total `price`.
- No database table/schema changes to v7.63.95 (schema 0211), so no destructive migration.
