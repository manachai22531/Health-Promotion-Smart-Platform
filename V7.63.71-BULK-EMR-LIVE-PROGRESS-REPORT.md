# v7.63.71 — Multi-project EMR Live Progress

## Changes
- Added a dedicated wide modal for multi-project EMR batch processing.
- The modal blocks the underlying project screen while processing so the user cannot click Receive EMR twice.
- Shows overall project/Booking progress, success/skip/error/pending counters, per-project progress, and a live Booking log table.
- Close controls are disabled until processing finishes; optional auto-close can be selected.
- Added project and text filters to the live log.
- Reduced the EMR status box in each compact project row to 170px and shortened its visible summary to `received / total`; full VN/percentage detail remains available in the tooltip.
- Expanded the inline remark area by removing its previous 260px cap.

## Production invariants
- Production only.
- `APP_ENV=production` behavior remains unchanged.
- Port 3000 behavior remains unchanged.
- Update Center root files remain at ZIP root: `server.js`, `package.json`, `VERSION.txt`, `INSTALL-REPAIR.bat`.
