HealthCheck v7.64.77 — Windows Production Installer
รวมงานเดิมถึง v7.64.76 พร้อมหน้าสรุปกระชับตามมอคอัพล่าสุด

วิธีติดตั้ง
1. ตรวจว่าไม่มีงานติดตั้ง/Update Center อื่นกำลังทำงาน และมีพื้นที่ว่างไดรฟ์ D: เพียงพอ
2. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ ห้ามเปิดไฟล์ติดตั้งจากภายใน ZIP
3. เปิด INSTALL-REPAIR.vbs และอนุญาต UAC
4. รอ Complete SUCCESS ตรวจเวอร์ชัน v7.64.77 แล้วกด Ctrl+F5
เป้าหมาย D:\HealthCheck\Production / Port 3000 / DB health_check_smart_search
รักษา .env ค่าระบบ และข้อมูลเดิม สำรอง Source และฐานข้อมูลก่อนเปลี่ยนระบบ
อย่าลบ Production/data หรือไฟล์ฐานข้อมูลเพื่อเพิ่มพื้นที่ว่าง

หาก Update Center รุ่นเก่ามีปัญหา Production health/version preflight failed
ใช้ REPAIR-UPDATE-CENTER.vbs จากชุดนี้ก่อนอัปโหลด ZIP ใหม่ หรือใช้ INSTALL-REPAIR.vbs โดยตรง
ห้ามเปิดตัวติดตั้งและ Update Center ซ้อนกัน

หน้าสรุปผู้รับบริการ
- หมายเหตุด้านหน้าเป็นข้อความอ่านอย่างเดียว ไม่มีช่องพิมพ์หรือปุ่มบันทึกหมายเหตุด้านหน้า
- กด เปิดข้อมูล ในส่วนชื่อผู้รับบริการ เพื่อแก้ไขและบันทึกหมายเหตุด้านใน
- ด้านในใช้ได้ทั้ง บันทึกหมายเหตุ และ บันทึกข้อมูล ตามสิทธิ์เดิม
- เมื่อไม่มีหมายเหตุ ยังคงหัวข้อ หมายเหตุเฉพาะบุคคล และข้อความ ยังไม่มีหมายเหตุ แบบย่อ
- เมื่อยังไม่เลือกคู่สัญญา ยังคงหัวข้อ แพ็กเกจคู่สัญญาที่เลือก, 0 รายการ และ ยังไม่ได้เลือกแพ็กเกจ
- ข้อมูลอื่นแสดงตามเดิม ไม่มีการเว้นกล่องว่างขนาดใหญ่สำหรับสองส่วนนี้
- ลดระยะห่าง/ความสูงแถวและหัวตาราง พร้อมยกเลิกการยืดกล่องคู่สัญญาให้สูงเกินเนื้อหา
- เมื่อมีข้อมูลจะแสดงรายละเอียดตามข้อมูลที่บันทึกไว้ และรายการคู่สัญญายังแสดงจำนวนรายการ
- วางบิล = ฟ้า, ชำระเอง = เขียว, แพ็กเกจหลัก = เหลือง ทาสีทุกเซลล์เพื่อให้ยังเห็นชัดทุกธีม

งานเดิมยังรวมอยู่
- หมายเหตุจาก Excel: หมายเหตุ / หมายเหตุเฉพาะบุคคล / Note / Notes / Remark / Remarks / PersonalNote
- ดูข้อมูลทั้งหมด / ตัวอย่างนำเข้า / ส่งออก Excel ใช้หมายเหตุเดียวกัน
- นำเข้าซ้ำโดยเว้นหมายเหตุว่างหรือไม่มีคอลัมน์ จะเก็บหมายเหตุเดิมไว้
- บันทึกแยกคนและบริษัท/ปี มีสิทธิ์และประวัติการแก้ไข ป้องกันการเขียนทับพร้อมกัน
- ปุ่มทั้ง 6 กลุ่มตามธีม สีแบรนด์หน้าลูกค้า และการส่งธีมระหว่างหน้าต่าง
- หน้าลูกค้าแบบตาราง เลือกบริษัท/ปี เล่มผลตรวจที่อนุมัติ และระบบนัดออกหน่วย/โรงพยาบาล
- EMR แบบตาราง วันที่วันนี้ รีวิว/พิมพ์เล่ม และหน้าตั้งค่าลูกค้าแยกสำหรับการตลาด
- ปุ่มโล่ EXP หน้าชื่อผู้ใช้ ปุ่มค้นหาจัดระดับเดียวกัน ระบบความปลอดภัยตาม Role
- งานเอกสารบริษัท Excel/PDF, Payor, ประวัติ Login และตัวติดตั้ง/Update Center เดิม
