ตัวติดตั้ง Production v7.64.80

รวมงานเดิมถึง v7.64.79 และเพิ่ม:
1. ลูกค้าเลือกโครงการและวันนัด ระบบใช้ Mobile=ออกหน่วยเฉพาะบริษัท / Inhouse=โรงพยาบาลโควตาร่วมโดยอัตโนมัติ ป้องกันการจองผิดประเภททั้งฝั่งหน้าจอและระบบ
2. เพิ่มแท็บ ลูกค้าจองนัด ต่อจาก สร้างตาราง ดู Day/Week/Month แสดงโควตา จำนวนจอง และคลิกช่วงเวลาดูรายชื่อได้
3. ปฏิทินเริ่ม 08:00 ถึง 08:00 วันถัดไป ช่องเริ่มต้น 30 นาที ปรับระยะจากหน้าสร้างตาราง การเปลี่ยนค่าไม่แก้ไขนัดเดิม
4. รองรับสร้างตารางข้ามวัน โดยเริ่มต้นช่วงสร้างครั้งละหนึ่งสัปดาห์เพื่อไม่เกิน 1,000 slot
5. หน้านัดหมายที่ดึงจากระบบโรงพยาบาลยังคงรูปแบบเดิม ปฏิทินแบบแบ่งเวลาปรับเฉพาะแท็บลูกค้าจองนัด

วิธีติดตั้ง: แตก ZIP ทั้งหมด เปิด INSTALL-REPAIR.vbs อนุญาต UAC รอ Complete SUCCESS แล้วกด Ctrl+F5 ตรวจเวอร์ชัน v7.64.80
สำรองและรักษาข้อมูล/การตั้งค่าเดิม ไม่เปิดตัวติดตั้งซ้อนกัน
ถ้า Update Center เก่าแจ้ง health/version preflight failed ให้ใช้ REPAIR-UPDATE-CENTER.vbs ก่อน หรือใช้ตัวติดตั้งตรง

ผ่าน build และ 53 release tests พร้อมทดสอบฐานข้อมูลจริงอัปเกรด 79->80 การจองและปฏิทินจริงใน Chromium
ยังไม่ได้รันขั้นตอนตัวติดตั้ง GUI/UAC/VBS/Task Scheduler บน Windows จริง
