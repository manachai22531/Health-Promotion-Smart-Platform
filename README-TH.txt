ตัวติดตั้ง Production v7.64.79

รวมทุกงานถึง v7.64.78 และรายการล่าสุด:
1. เอาปุ่มเปิดข้อมูลใต้ชื่อลูกค้าออก คลิกการ์ดเข้าดูได้ตามเดิม
2. EXP: เหรียญผลงานล่าสุด ผลงานวันนี้แยกประเภท และประวัติรับ/ยกเลิก EXP ของตนเอง
3. หน้าลูกค้า: เบอร์โทร/อีเมลอยู่ข้างชื่อ ปุ่มแก้ไขข้อมูลส่วนบุคคลเปิดหน้าต่างใหม่ เอากล่องแก้ไขเดิมออก
4. หน้านัดหมาย: สองแท็บใหญ่ นัดหมาย / สร้างตาราง เอาคำว่า HIS ออกจากชื่อหน้าและข้อความนัดหมาย โดยระบบเชื่อมต่อเดิมยังทำงาน
5. คงหน้าตัวอย่างลูกค้า โฆษณาสองหน้า บทความสุขภาพผูกแพ็กเกจ และงานก่อนหน้าทั้งหมด

วิธีติดตั้ง: แตก ZIP ทั้งหมด เปิด INSTALL-REPAIR.vbs อนุญาต UAC รอ Complete SUCCESS แล้วกด Ctrl+F5 ตรวจเวอร์ชัน v7.64.79
สำรองและรักษาข้อมูล/การตั้งค่าเดิม ไม่เปิดตัวติดตั้งซ้อนกัน
ถ้า Update Center เก่าแจ้ง health/version preflight failed ให้ใช้ REPAIR-UPDATE-CENTER.vbs ก่อน หรือใช้ตัวติดตั้งตรง

ผ่าน build และ 51 release tests พร้อมทดสอบฐานข้อมูลจริงอัปเกรด 78->79 และหน้าจอจริงใน Chromium
ยังไม่ได้รันขั้นตอนตัวติดตั้ง GUI/UAC/VBS/Task Scheduler บน Windows จริง
