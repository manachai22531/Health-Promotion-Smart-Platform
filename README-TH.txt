ตัวติดตั้ง Production v7.64.78

รวมทุกงานถึง v7.64.77 และเพิ่ม:
1. ปุ่มดูตัวอย่างหน้าเลือกรายการลูกค้า ใช้ข้อมูลสมมติ ไม่ต้องกรอก ID/วันเกิด และไม่ส่งคำสั่งซื้อจริง
2. แบนเนอร์ประชาสัมพันธ์แยกหน้าล็อกอิน/หน้าเลือกแพ็กเกจ ตั้งค่า URL รูป HTTPS ลิงก์ คำอธิบาย และเปิดปิดได้
3. ปุ่มความรู้สุขภาพ ค้นหาบทความ ดูแหล่งอ้างอิง ผู้ทบทวน และไปยังแพ็กเกจที่เกี่ยวข้องตามสิทธิ์บริษัท/ปี
4. ฝ่ายการตลาดจัดการบทความและสถานะเผยแพร่จากหน้าตั้งค่าลูกค้าได้ บทความที่ยังไม่เผยแพร่ไม่ส่งออกให้ลูกค้า

วิธีใช้: แตก ZIP ทั้งหมดไปโฟลเดอร์ใหม่ เปิด INSTALL-REPAIR.vbs อนุญาต UAC รอ Complete SUCCESS แล้วกด Ctrl+F5 ตรวจเวอร์ชัน v7.64.78
ข้อมูลและการตั้งค่าเดิมจะสำรองและรักษาไว้ ไม่ควรเปิดตัวติดตั้งซ้อนกัน
ถ้า Update Center รุ่นเดิมแจ้ง health/version preflight failed ให้ใช้ REPAIR-UPDATE-CENTER.vbs ก่อน หรือใช้ตัวติดตั้งโดยตรง

ผ่านการทดสอบ 44 release tests, build, ฐานข้อมูลจริงอัปเกรด 77->78, หน้าตั้งค่าลูกค้า/บทความ/ตัวอย่างร้านจริงใน Chromium และการตรวจไฟล์ติดตั้ง
ยังไม่ได้รันขั้นตอน GUI/UAC/VBS/Task Scheduler บน Windows จริง
