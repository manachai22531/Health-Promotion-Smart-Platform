HealthCheck v7.64.74 — Windows Production Installer
รวมงานทั้งหมดถึงม็อกอัปล่าสุดและการแก้ไข v7.64.68–73

ติดตั้งโดยตรง
1. ปิดตัวติดตั้ง/ตัวอัปเดตเดิมที่สิ้นสุดแล้ว ห้ามเปิดซ้อนกัน
2. ตรวจพื้นที่ว่าง D: หากไม่พอ ย้าย ZIP สำรองเก่าที่ต้องเก็บไปไดรฟ์อื่น
   ห้ามลบ Production/data, .env หรือฐานข้อมูล PostgreSQL
3. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ เปิด INSTALL-REPAIR.vbs และอนุญาต UAC
4. รอ Complete SUCCESS ตรวจเวอร์ชัน v7.64.74 แล้วกด Ctrl+F5
เป้าหมาย D:\HealthCheck\Production / port 3000 / health_check_smart_search
รักษา .env/ค่าระบบเดิม และสำรอง Source กับฐานข้อมูลก่อนอัปเกรด

หน้าเซตอัพหน้าลูกค้าแยกสำหรับการตลาด
- เปิดจาก ข้อมูลบริษัท → ตั้งค่าหน้าลูกค้า ↗ หรือ /customer-setup
- เปิดหน้าต่างใหม่และใช้บัญชีเจ้าหน้าที่เดิม หากล็อกอินอยู่จะใช้ Session เดิมได้
- รองรับบังคับเปลี่ยนรหัสผ่าน/Password Expired/Idle Logout ตาม Role เดิม
- สิทธิ์ใหม่ customerPageManage ใช้ตั้งค่าหน้าลูกค้าโดยเฉพาะ ไม่ต้องให้ apiManage
- อัปเกรดจะเพิ่มสิทธิ์นี้หนึ่งครั้งให้ Role id admin และ marketing ที่มีอยู่
  ไม่เพิ่มสิทธิ์ API/HIS อื่น หากผู้ดูแลถอนสิทธิ์ภายหลัง ระบบไม่เพิ่มกลับเอง
  Role อื่นหรือ Role การตลาดที่ตั้งชื่อเองให้ผู้ดูแลกำหนดสิทธิ์หน้าลูกค้าใน Role
- ปรับข้อความไทย/อังกฤษ สี ภาษาเริ่มต้น ความกว้าง ระยะห่าง และเปิด/ปิดโลโก้
  ปุ่มภาษา ปุ่มอ่านบัตร ปุ่มไม่ทราบ ID และส่วนช่วยเหลือ/ช่องทางติดต่อได้
- พรีวิวสดจอทั่วไป/มือถือในพื้นที่แยกที่ไม่มีข้อมูลผู้ป่วย
- บันทึกใช้ร่วมกันทุกบริษัท มีประวัติแก้ไขและป้องกันผู้ดูแลบันทึกทับกัน
- คืนค่าเริ่มต้นเป็นเพียงค่าในแบบฟอร์มจนกว่าจะกดบันทึก
- ลูกค้าเห็นค่าใหม่เมื่อเปิด/รีเฟรช /customer การยืนยันตัวตนและ Session เดิมไม่เปลี่ยน

EMR: วันนี้ / รีวิว / พิมพ์เล่ม
- วันที่เริ่ม–สิ้นสุดตั้งเป็นวันนี้ตามเวลาไทย พร้อมปุ่ม วันนี้ / ทุกวัน
  ถ้าต้องการดูเคสเก่าให้กด ทุกวัน ข้อมูลเดิมไม่ได้หายไป
- มีตัวกรอง ผลตรวจครบแล้ว และ พร้อมพิมพ์ (อนุมัติแล้ว)
- เพิ่มปุ่ม รีวิวเล่ม / พิมพ์เล่ม ในแต่ละแถว และเลือกพิมพ์หลายเล่ม (สูงสุด 25)
- รีวิวเป็น PDF จากข้อมูลจริง เล่มยังไม่อนุมัติแสดงลายน้ำ DRAFT ทุกหน้า
- พิมพ์ฉบับจริงต้องมีการอนุมัติสำหรับ VN ของเคส และตรวจซ้ำที่เซิร์ฟเวอร์
- แพทย์เปิดได้เฉพาะเคสที่ได้รับมอบหมาย ข้อมูลใน PDF จำกัดเฉพาะ VN นั้น
- เปิด PDF สำหรับพิมพ์ในหน้าต่างใหม่และเรียกหน้าพิมพ์ของเบราว์เซอร์
  หากเบราว์เซอร์ไม่เปิดหน้าพิมพ์อัตโนมัติ ใช้ปุ่มพิมพ์ในตัวแสดง PDF
  ต้องอนุญาต Pop-up สำหรับระบบนี้
- คงหน้าทำเล่มเต็มพื้นที่ แบบร่าง/อนุมัติ/แปลผลเดิม พร้อมกลับตาราง
- บันทึกประวัติการรีวิว/พิมพ์ และแสดงเวลารีเฟรชล่าสุดเมื่อรีเฟรชสำเร็จ
- แนบฟอนต์ไทยสำหรับ PDF กรณีเครื่องไม่มี Tahoma

หน้าค้นหาตามม็อกอัปล่าสุด
- ปุ่มข้อมูลบริษัทสูงเท่าปุ่มค้นหา/ล้างข้อมูล/เพิ่มลูกค้าในแต่ละระดับความหนาแน่น
- ซ่อนรายชื่อยืนยันเริ่มต้น พื้นที่ค้นหาและข้อมูลลูกค้าใช้เต็มความกว้าง
- กด ยืนยันแล้ววันนี้ เพื่อเปิดแถบด้านขวา ปิดด้วย ×, Esc หรือคลิกพื้นที่นอกแถบ
- แถบแสดงจำนวนและรายชื่อยืนยันของวันนี้ตามเวลาไทย ไม่จำกัดเพียง 8 รายเดิม
  กด เปิดข้อมูล เพื่อเปิดรายละเอียดลูกค้าได้
- คงการค้นหา เมนูข้อมูลบริษัท และตัวเลือกอื่นเดิม

รวมการแก้ไขก่อนหน้าทั้งหมด
- EMR ตารางรวม, Worklist ตารางรวมทุกขั้นตอน และการลบกล่องสรุป/หัวข้อซ้ำตามกรอบแดง
- หน้าค้นหาลบหัวข้อ/คำแนะนำ/ข้อความฐานข้อมูลและหัวข้อบนแถบยืนยันตามที่ตกลง
- ปุ่มบันทึก 02–04 บริษัทใหม่พร้อมปี สลับ 00/01 ในฟอร์ม โดยลำดับ PDF เดิม
- Password Expired/Idle Logout ค่าเริ่มต้น 15 นาทีตาม Role ประวัติ Login
- แผงตั้งค่าและประกายดาว ตรวจแบบไม่ฟังผล ไม่มีคูปองอาหาร free text แทน Walk in
- ยกเลิกตาราง เทมเพลต/นำเข้า Excel แนบ PDF ตารางโปรแกรม
- Master Payor/Plan บริษัทในเครือ แพ็กเกจที่เลือกขยายเต็มพื้นที่ ซ่อนแถบ HIS จนยืนยัน
- ตัวติดตั้งหน้าต่างเดียว live log/heartbeat และแก้ Production preflight

สำรองไฟล์/พื้นที่ดิสก์
- Source สำรองลง ZIP โดยตรง ไม่ทำสำเนา Source ทั้งชุดไป temp ก่อน
- ตรวจพื้นที่ก่อนสั่งหยุดแอปและตรวจ snapshot ซ้ำ เผื่อ Source ZIP + payload + 1 GiB
  ฐานข้อมูลและการติดตั้ง dependencies อาจต้องใช้พื้นที่เพิ่มจากขั้นต่ำนี้
- เก็บ .env/hidden config และ data/uploads ไม่ลบ backup เก่าอัตโนมัติ
- แสดงความคืบหน้าและลบเฉพาะ partial ZIP ที่เขียนไม่สำเร็จของงานนั้น
- สำรองฐานข้อมูลยังเป็นขั้นตอนบังคับ

สำหรับ Update Center เก่า v7.64.68 ที่ preflight ไม่ผ่าน
แตก ZIP นี้ เปิด REPAIR-UPDATE-CENTER.vbs หนึ่งครั้งก่อน แล้ว Upload ZIP ใหม่
หรือใช้ INSTALL-REPAIR.vbs โดยตรง ตัวซ่อมสำรอง helper เดิม ไม่หยุดแอป/ไม่แก้ DB

ทดสอบบน PostgreSQL แยก, Chromium และ PowerShell core บน Linux แล้ว
ยังไม่ได้รันตัวติดตั้งเต็มขั้นตอน Windows GUI/UAC/Robocopy/Task Scheduler
หรือทดสอบเครื่องพิมพ์จริง ให้ใช้คู่มือฉบับ v7.64.74 นี้เป็นหลัก
