# HealthCheck v7.64.22 PRODUCTION — Global Golden Sparkle

## Changes
- Adds a global golden sparkle effect to enabled button controls.
- Uses a fixed, top-level viewport layer and scale-corrected pointer coordinates so the burst begins at the pointer under UI density, CSS transform, zoom, and Windows display scaling.
- Each activation emits 6–10 gold stars travelling 20–45px for 0.5–0.8 seconds.
- Disabled controls do not emit sparkles; reduced-motion settings suppress the animation.

## Compatibility
- Production only, Windows, port 3000, database `health_check_smart_search`.
- Existing `.env` and database are preserved by the installer workflow.
- No live Windows/PostgreSQL/HIS installation was performed during packaging.
