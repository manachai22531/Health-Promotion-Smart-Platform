HealthCheck v7.64.47 — shared HTML/PDF summary
1. แสดงสรุป A4 แบบ HTML ระหว่างทำงาน เปลี่ยนข้อมูลและแพ็กเกจแล้วแสดงผลทันทีโดยไม่สร้าง PDF ทุกครั้ง
2. HTML และ PDF ใช้แม่แบบ HTML/CSS และฟอนต์เดียวกัน ขนาด A4 รองรับภาษาไทย QR HN และการรวมประเภท/สถานี
3. แสดงสถานะข้อมูลยังไม่บันทึก เตือนก่อนปิด และคงรายการแก้ไขที่ยังไม่ได้บันทึกหลังบันทึกข้อมูลบางส่วน
4. สร้าง PDF เมื่อกดพรีวิว PDF / พิมพ์ A4 หรือ Ctrl+P ใช้เฉพาะข้อมูลบันทึกแล้ว เปิดแถบเครื่องมือ PDF เพื่อพิมพ์หรือดาวน์โหลด
5. ใช้ PDF เดิมซ้ำเมื่อข้อมูลบันทึกไม่เปลี่ยน และไม่เปิด PDF กลับขึ้นมาหลังปิดหน้าผู้ป่วย
คงฟังก์ชันเดิม: คู่สัญญาชำระเอง, รายการแพ็กเกจและ QR HN, หน้าลูกค้าสั่งแพ็กเกจ, ChargeClose, EXP/Role และ workflow HIS
ไม่มี migration ใหม่ เอกสารยาวต่อหน้าถัดไปเพื่อรักษาความอ่านง่าย

ข้อกำหนด: เครื่องเซิร์ฟเวอร์ต้องติดตั้ง Microsoft Edge หรือ Google Chrome สำหรับสร้าง PDF
กำหนดพาธเพิ่มเติมได้ด้วย HEALTHCHECK_PDF_BROWSER โปรแกรมใช้ playwright-core และไม่ดาวน์โหลดเบราว์เซอร์เพิ่ม
ติดตั้ง: Application Update > Upload ZIP > Preflight Only > Install Update
หรือแตก ZIP ลงโฟลเดอร์ใหม่แล้ว Run as administrator ที่ INSTALL-REPAIR.bat
สำรองฐานข้อมูลและ .env ก่อนอัปเดต ตรวจ /api/version เป็น v7.64.47
