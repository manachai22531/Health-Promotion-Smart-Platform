HealthCheck v7.65.08 Production Windows Installer

รวมความสามารถทั้งหมดจาก v7.65.07 พร้อมปรับหน้าค้นหาและรายชื่อลูกค้าตามมอคอัพที่อนุมัติ

1. ตัวกรองชื่อ, ID / Passport, HN, บริษัท, Booking, ปุ่มค้นหา, ล้างข้อมูล, เพิ่มลูกค้า, ข้อมูลบริษัท, ยืนยันแล้ววันนี้ และสวิตช์แบบเดิม/แบบตาราง อยู่ในแถวเดียวบนหน้าจอ Desktop
2. นำแถบปุ่มทำรายการรายบุคคลออกจากเหนือหัวตารางทั้งหมด
3. โหมดตารางยังเลือกได้ทีละหนึ่งรายการด้วย radio และการคลิกแถวหรือ radio จะเปิดเนื้อหารายละเอียดลูกค้าทันที
4. การแก้ข้อมูล ยืนยันการตรวจ เปิดหน้าลูกค้า ดูนัดหมาย ดูเล่ม และงานเอกสาร ใช้ปุ่มภายในหน้ารายละเอียดเดิม จึงคงการตรวจสิทธิ์และขั้นตอนเดิมของระบบ
5. ปุ่ม Export ยังคงอยู่เหนือรายการเพราะเป็นคำสั่งระดับตาราง ไม่ใช่คำสั่งรายบุคคล
6. โหมดการ์ดเดิมและข้อมูลทุกหัวข้อยังคงอยู่ครบ

ตัวติดตั้งรักษา .env, API key, การเชื่อมต่อฐานข้อมูล และข้อมูลเดิม พร้อม backup, integrity check, migration, health check และ rollback ตาม Production Installer เดิม

ติดตั้ง: แตก ZIP ทั้งหมด แล้วเปิด INSTALL-REPAIR.bat ด้วย Run as Administrator
เป้าหมายมาตรฐาน: D:\HealthCheck\Production, port 3000, database health_check_smart_search
