# v7.63.66 — Sticky Legacy Conflict Fix

## Root cause
The unified table introduced in v7.63.64/65 correctly marked only Select / Row / HN / VN and EMR Summary / Actions as sticky, but older CSS rules from the Project Booking and Customer List screens were still active. In particular, legacy `nth-child(-n+9)` and `customer-display-order` rules continued to force additional columns to `position: sticky`, with old `left` offsets. This caused headers and cells to drift/mismatch while horizontal scrolling.

## Fix
- Hard-reset legacy sticky positioning for every unified-table column that is not explicitly marked sticky.
- Reset legacy `left` / `right` offsets on grouped headers.
- Keep only Select / Row / HN / VN sticky left.
- Keep only EMR Summary / Actions sticky right.
- Remove the old Project Booking DisplayOrder highlight/sticky side effects from the unified table.
- Preserve HN/VN highlighting and row hover behavior.
- Apply the same schema to Project Booking and Company customer tables.

## No functional changes
OCR, A4, HIS/EMR workflow, Booking move, and database schema are unchanged.
