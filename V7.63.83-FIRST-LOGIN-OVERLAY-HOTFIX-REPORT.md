# HealthCheck v7.63.83 — First Login Overlay Hotfix

## Cause
The login screen used `z-index: 1000`, while the shared modal overlay used `z-index: 100`. The forced first-login password dialog opened correctly but rendered behind the login screen.

## Fix
- Added a dedicated stacking layer for `#firstLoginChangeOverlay` above the login screen.
- Kept the dialog non-dismissible until the personal password is saved.
- Preserved the v7.63.82 one-time token and no-session-before-password-change controls.
