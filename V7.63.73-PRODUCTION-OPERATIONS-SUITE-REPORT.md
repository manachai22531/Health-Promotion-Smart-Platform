# HealthCheck v7.63.73 Production Operations Suite

## Release identity
- Release: `v7.63.73-production`
- Runtime: Production only
- `APP_ENV=production`
- `PORT=3000`
- PostgreSQL database: `health_check_smart_search`
- Schema version: `0200`
- Base release: `v7.63.72`

## Scope implemented

### 1. Error Center + งานค้าง
เพิ่มเมนู **ศูนย์ปฏิบัติการ** พร้อม KPI และรายการงานค้างจากข้อมูลจริง:
- ไม่มี HN
- ไม่มี VN
- มี HN/VN แต่ยังไม่มี EMR
- HIS/patientlog status error
- ค้นหาและกรอง HN, VN, ชื่อ, บริษัท และโครงการ
- ดำเนินการจากรายการได้โดยตรงตาม Permission

### 2. Audit Log
เพิ่ม `system_action_audit` สำหรับเก็บประวัติ API ที่มีการเปลี่ยนข้อมูล (`POST/PUT/PATCH/DELETE`):
- User/Actor
- Endpoint และ Method
- HTTP status
- Client address
- Duration
- เวลา
- เก็บเฉพาะ metadata ที่จำเป็น ไม่บันทึก request body เพื่อลดการเก็บ PII/secret ซ้ำ

หน้า Audit Log รวมข้อมูล system action, workflow audit และ permission audit เพื่อค้นย้อนหลังจากหน้าเดียว

### 3. Persistent Job Queue + Retry
เพิ่ม Job Queue บน PostgreSQL:
- `CHECK_HN`
- `CHECK_VN`
- `BULK_EMR`
- `REFRESH_PATIENTLOG`
- `SYSTEM_HEALTH`
- `BACKUP`

ความสามารถ:
- Progress / Success / Skip / Failed
- รายละเอียดต่อคน
- Retry เฉพาะ Failed / Partial / Cancelled
- Cancel งาน Pending / Running
- ป้องกัน enqueue งานชนิด+payload เดียวกันซ้ำขณะที่ยัง Pending/Running
- กู้คืน Job ที่ถูกขัดจังหวะหลัง Server restart แล้วนำกลับเข้าคิว
- งาน Batch ทำงานเบื้องหลัง ผู้ใช้ไม่จำเป็นต้องค้างอยู่หน้าเดิม

### 4. System Health + Performance
เพิ่มหน้า System Health / Performance ใน Operations Center:
- Database latency
- PostgreSQL pool total / idle / waiting
- Disk free
- Process memory
- Uptime
- Slow / Critical events
- Update Center phase/status
- Health Job สำหรับตรวจแบบ manual และ scheduled ทุก 30 นาที

### 5. Permission ระดับ Action
ใช้ Permission model เดิมกับ Operations Center ทั้ง UI และ API:
- HN/VN/EMR job: `emrAssign`
- Patientlog refresh: `projectView`
- Backup: `apiManage`
- System health: `apiView`
- Audit: `auditView`
- Operations Center: `worklistView`

ปุ่ม Retry/Cancel จะตรวจ Permission ตามชนิด Job จริงทั้งฝั่ง UI และ Server

### 6. PostgreSQL Performance Indexes
Migration `0200_operations_center.up.sql` เพิ่ม index สำหรับงานที่ใช้บ่อย:
- Booking HN
- Booking record key
- Booking status + updated time
- Visit VN
- Visit result status
- Workflow audit time
- Job queue/status
- Job item status
- Action audit actor/route/time
- Notification unread

Migration เป็น transactional (`BEGIN/COMMIT`) เพื่อใช้กับ Update Center ได้อย่างปลอดภัย

### 7. Backup + Update Center Rollback
- เพิ่มปุ่มสร้าง PostgreSQL Backup ผ่าน Job Queue สำหรับ Production Windows Server
- หน้า Backup แสดงรายการไฟล์ Backup และเวลาสำรองล่าสุด
- แสดงสถานะ Automatic Rollback ของ Update Center
- Update Center เดิมยังสำรอง Source + Database ก่อน Deploy และ rollback อัตโนมัติหาก Deploy/Migration/Health ไม่ผ่าน
- แก้ `tools/backup.ps1` ให้ชื่อไฟล์ Backup อ่าน Version ปัจจุบันจาก `VERSION.txt` แทนชื่อเก่าแบบ hard-code

### 8. Internal Notification
เพิ่ม `system_notifications` และหน้า Notification ภายในโปรแกรมสำหรับ:
- Job สำเร็จ
- Job สำเร็จบางส่วน
- Job Error
- Job ถูกยกเลิก
- System Health warning

มี badge บนเมนู Operations Center และทำเครื่องหมายว่าอ่านแล้วได้

### 9. Auto Refresh HIS/patientlog Status
หน้า Project Booking refresh สถานะ `patientlog` อัตโนมัติทุก 15 วินาทีขณะเปิดหน้า Booking:
- ใช้ HN + VN
- ใช้ endpoint batch เดิม
- เปลี่ยนเฉพาะแถวเมื่อ status เปลี่ยน
- ไม่ refresh ทั้งหน้า
- ยังใช้ latest `patientlog.tovalue` ตาม `insdate DESC`, `id DESC` จาก v7.63.72

### 10. Automated Regression Test
เพิ่ม `release-candidate-v76373-operations-suite.test.js` ครอบคลุม:
- Production-only release identity
- Update Center root structure
- Operations Center + Error Center
- Persistent Job Queue / Retry / Cancel / duplicate protection / restart recovery

- Health / Performance / Backup / Rollback / Notification
- patientlog auto refresh
- Migration 0200 + indexes
- Regression ของ Requirement v7.63.72 (Booking package/status/close button/User-HIS)
