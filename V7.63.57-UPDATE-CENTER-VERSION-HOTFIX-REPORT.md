# v7.63.57 Update Center Version Hotfix

## Symptom
Update Center accepted the uploaded filename as v7.63.57 but Preflight rejected it with: `แพ็กเกจ v7.63.56 ต้องใหม่กว่า v7.63.56`.

## Root cause
`tools/app-update-helper.js` validates the package version from `RELEASE_NAME` inside `server.js`. The original v7.63.57 package had `package.json = 7.63.57` but `server.js` still declared `v7.63.56-production`.

## Fix
- `server.js` now declares `v7.63.57-production`.
- `UPDATE-MANIFEST.example.json` updated to v7.63.57.
- v7.63.57 regression test now checks both `package.json` and `server.js` release identity.
- No database migration or data change is required.

## Update path
Current v7.63.56 -> corrected v7.63.57 via Update Center.
