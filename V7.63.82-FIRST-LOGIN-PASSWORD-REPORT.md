# HealthCheck v7.63.82 — First Login Password Management

## Scope
Production update based on v7.63.81. Adds administrator-managed first-login credentials for HIS users without changing the administrator password baseline.

## Changes
- Admin can define one shared first-login password for newly synchronized HIS users.
- Selected users can be reset in bulk to the current first-login password.
- Reset accounts are active but marked `mustChangePassword` and cannot receive a normal application session.
- First login returns a short-lived, one-time change token and opens a non-dismissible password-change screen.
- The new personal password must be at least 10 characters, contain a letter and a number, and differ from the first-login password.
- Successful change records `firstLoginAt` and `passwordChangedAt`, clears `mustChangePassword`, and writes an Audit Log entry.
- Only password hashes are stored in application state; the shared plaintext password is never persisted.
- Existing custom passwords are preserved unless the administrator explicitly selects and resets those accounts.

## Compatibility
- Production only: `APP_ENV=production`
- Production port: `3000`
- v7.63.81 administrator password migration remains intact.
- v7.63.80 HIS role mapping and filtered sync remain intact.
