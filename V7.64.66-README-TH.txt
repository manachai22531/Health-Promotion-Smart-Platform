HealthCheck v7.64.66
ฐาน: ตัวติดตั้ง v7.64.65 ครบชุด คงการปรับความเร็วจาก v7.64.61

สิ่งที่เพิ่มรอบนี้
- เอกสารเวียน PDF ธีมสีน้ำเงิน–เขียวตามโลโก้ ViMUT
- หัวกระดาษโลโก้ซ้าย ชื่อเอกสารและบริษัท วันที่/เลขที่หนังสือขวา
- ไม่ใส่แถวหัวข้อเลข 01–03 ตามมอคอัพ
- ตารางหัวข้อสีน้ำเงิน แถวสลับสีอ่อน ช่องไม่มีสิทธิ์สีเทาอ่อน
- คอลัมน์ Code ในรายการตรวจเพิ่มเติม ถัดจากการชำระ ก่อนชื่อรายการ
- ตารางโปรแกรมพนักงานแสดงราคา/รหัสชัดเจน
- คง A4 ข้อมูลตัวอย่างเดิมได้ 3 หน้าระบบ + 2 หน้าแนบ รวม 5 หน้า
- ข้อมูลยาวจะเพิ่มหน้า ไม่ตัดหางรายการ และยังมีสารบัญหัวข้อ PDF
- เอกสารแนบที่ผู้ใช้อัปโหลดยังคงเป็นต้นฉบับ ไม่เปลี่ยนหน้าตาหรือข้อมูล
- ฝัง Sarabun ไทย/อังกฤษพร้อมใบอนุญาต ทำให้เปิด PDF ได้โดยไม่ต้องติดตั้งฟอนต์เพิ่ม

ความเร็ว
- ใช้การหาจุดตัดบรรทัด PDF แบบ exponential/binary search และแคชความกว้างเฉพาะงาน
- แคชไบต์ฟอนต์/โลโก้แบบจำกัดขนาด ตรวจ mtime/ขนาดไฟล์ก่อนใช้ซ้ำ
- คำนวณข้อความค้นหา Order ไว้กับแคตตาล็อก แทนการ normalize ทุกตัวซ้ำแต่ละครั้ง
- เปรียบเทียบก่อน/หลังด้วยข้อมูลเดียวกัน ตรวจผลลัพธ์และบรรทัดที่ตัดตรงกัน
- เป็นการเพิ่มความเร็วเฉพาะส่วน ไม่ใช่การรับรองความเร็วรวมของ HIS/ระบบจริง

คงฟังก์ชันจาก v7.64.65
- Excel Order&Station พร้อม preview/revision/audit
- Windows Task Scheduler เริ่มระบบหลังเปิดเครื่อง ไม่ต้องล็อกอิน
- ไอคอนคัดลอกท้ายช่อง แถบปุ่มแถวเดียว ปุ่มปิด PDF เล็ก และ navigator
- ฟังก์ชัน Booking, HIS 2 ชั้น, QR ลูกค้า, สิทธิ์ย้อนหลัง และอื่น ๆ เดิม

วิธีติดตั้ง
1. สำรองข้อมูล
2. แตก ZIP ทั้งหมด แล้วเปิด INSTALL-REPAIR.bat ตามขั้นตอนเดิม
3. เปิดเว็บ ตรวจรุ่น v7.64.66
4. PDF ที่บันทึกไว้ก่อนอัปเดตยังเป็นแบบเดิม ต้องสร้าง PDF ใหม่เพื่อใช้รูปแบบใหม่

ไม่ได้ทดสอบ Windows/HIS/ฐาน Production จริงในสภาพแวดล้อมนี้
ไม่มี Dependency เพิ่มหรือ Migration ใหม่
