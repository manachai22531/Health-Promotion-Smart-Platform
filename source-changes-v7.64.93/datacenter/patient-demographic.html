ลำดับการค้นหา: ID → Passport → ชื่อ + นามสกุล (กรองด้วยวันเกิด/Gender ถ้ามี)

ไปขั้นถัดไปเมื่อขั้นก่อนหน้าไม่พบเท่านั้น ค้นด้วยชื่อ–นามสกุลอย่างเดียวได้ ผลจากชื่อต้องตรวจเลือกผู้ป่วยก่อนนำ HN ไปใช้

ใช้การเชื่อมต่อเดียวกับ Patient Package / Radiology ใน System & API · ค้นหาอย่างเดียว ไม่แก้ไขข้อมูล HIS หรือรายชื่อบริษัท

รองรับ FirstName, LastName, DOB, Gender, ID, Passport หรือหัวคอลัมน์ภาษาไทย · วันเกิด DD/MM/YYYY หรือ YYYY-MM-DD (พ.ศ./ค.ศ.) · Gender: M/F, Male/Female, ชาย/หญิง · ID/Passport ควรตั้งรูปแบบเซลล์เป็น Text เพื่อรักษาเลข 0 ด้านหน้า
