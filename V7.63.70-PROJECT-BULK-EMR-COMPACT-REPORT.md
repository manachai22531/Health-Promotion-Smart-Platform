# v7.63.70 — Project Bulk Booking / EMR Compact UI

## Changes
- Project page cards are now compact to show more Booking rows per screen.
- Project remarks are rendered inline with package information rather than in a standalone note box.
- Multi-project selection is available through per-project checkboxes and Select All.
- Hero actions show selected project count, Select Booking, and Batch Receive EMR.
- Batch Receive EMR loads Booking rows from all selected projects, skips rows without HN/VN, deduplicates the same record/VN, and reuses the existing HIS EMR endpoint.
- Project EMR progress is displayed inside each compact row.
- Existing per-project Manage / Edit / Delete actions remain unchanged.
