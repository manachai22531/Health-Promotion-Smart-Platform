### HIS User Query visibility
- Added `/api/his-users/query` (read-only, `userView` permission).
- The system reads `information_schema.columns`, maps available HIS columns, and builds the exact SELECT used by User Sync.
- Query preview never includes database passwords or API secrets.
- Added a **ตาราง User (HIS)** section in Database/DataCenter Settings showing schema, table/view, and current query preview.

### Query pattern
```sql
SELECT <mapped id>,
       <mapped username>,
       <mapped code>,
       <mapped title>,
       <mapped firstname>,
       <mapped middlename>,
       <mapped lastname>,
       <mapped display name>,
       <mapped department>,
       <mapped position>,
       <mapped email>,
       <mapped phone>,
       <mapped active>,
       <mapped deleted>
FROM "<schema>"."<doctorTable/usermas>" u
LIMIT 5000;
```
The exact column expressions are generated from columns that actually exist in the configured HIS User table.
