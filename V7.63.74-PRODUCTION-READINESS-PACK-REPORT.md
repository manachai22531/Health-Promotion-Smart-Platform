## สิ่งที่เพิ่ม

### 1. Production Readiness Center
เพิ่มแท็บ **Production Readiness** ในศูนย์ปฏิบัติการ เพื่อรวมผลตรวจความพร้อมก่อนใช้งานจริงในหน้าเดียว

### 2. UAT Checklist
มีรายการ UAT หลัก 8 flow:
- Login / Role / Permission
- Project Booking
- HN / VN
- patientlog Status
- Bulk EMR
- HIS User Sync
- Backup / Restore
- Update / Rollback

ผล UAT ถูกเก็บใน PostgreSQL พร้อมสถานะ `PENDING / PASS / FAIL / BLOCKED`, หมายเหตุ, ผู้ตรวจ และเวลา

### 3. Safe Load Benchmark
เพิ่ม Load Test แบบ **read-only** สำหรับตรวจ PostgreSQL/app latency โดยไม่สร้างหรือแก้ข้อมูลผู้ป่วย:
- 5–500 requests
- concurrency 1–20
- แสดง min / p50 / p95 / max latency และ error count

มี UAT document กำหนด matrix สำหรับ 1,000 / 5,000 / 10,000 Booking ใน Production-like environment

### 4. Backup Integrity + Restore Verification
- ตรวจ Backup ล่าสุด
- คำนวณ SHA-256 แบบ streaming ไม่ block ด้วยการอ่านทั้งไฟล์เข้าหน่วยความจำ
- แสดงขนาด/เวลา Backup
- ระบุขั้นตอน Restore Drill ที่ต้องยืนยันบนฐานทดสอบหรือ Maintenance window

### 5. Rollback Drill Validation
เพิ่มการตรวจ prerequisite แบบไม่ทำ Rollback Production จริง:
- Updater helper
- Restore script
- Database backup
- Update directory writable
- Current Update Center status

### 6. Security Audit + Hardening
เพิ่ม baseline hardening:
- ปิด `X-Powered-By`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: SAMEORIGIN`
- `Referrer-Policy: same-origin`
- restrictive `Permissions-Policy`
- Login brute-force throttle: ผิด 5 ครั้งในช่วง 15 นาที → lock 5 นาที
- ตรวจ HttpOnly/SameSite session cookie
- ตรวจ server-side permission guard
- ตรวจว่า runtime `.env` ไม่ถูกวางใน public path

### 7. Database Maintenance
แสดงข้อมูลจาก PostgreSQL:
- `pg_stat_user_tables`
- `pg_stat_user_indexes`
- table sizes
- live/dead rows
- analyze/autovacuum timestamps
- connection pool
- recommendation เมื่อ dead rows สูง

มี endpoint `ANALYZE` ที่จำกัดเฉพาะ table allowlist และต้องมี `apiManage` permission

### 8. Release Gate
เพิ่ม `npm run test:release` ครอบคลุม:
- JavaScript syntax
- Production identity
- Update Center survival
- Readiness UI/API
- Migration 0210
- Load test bounds/read-only rule
- Backup/Rollback validation
- Security hardening
- DB maintenance allowlist
- regression ของ Operations Suite + requirement ก่อนหน้า
