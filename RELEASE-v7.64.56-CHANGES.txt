สร้าง Booking: เมื่อเลือกบริษัท/ปี ระบบคัดลอกแพ็กเกจพนักงานและครอบครัวจากข้อมูลบริษัทรายปี และชุด Payor / Plan / Office ที่สัมพันธ์กันใน Master มาเป็นค่าเริ่มต้น
เพิ่ม เปลี่ยนรหัส เปลี่ยนกลุ่ม หรือลบแพ็กเกจได้ เพิ่ม แก้ไข หรือลบชุด Payor ได้ตามสิทธิ์ มีปุ่มดึงข้อมูลบริษัทอีกครั้งที่ถามก่อนแทนที่รายการในฟอร์ม
ข้อมูลถูกเก็บเป็น snapshot เฉพาะ Booking เปิดกลับมาไม่โหลดต้นทางทับรายการที่แก้ไว้ การแก้ Booking ไม่แก้ข้อมูลบริษัท มี audit ก่อน/หลังพร้อมผู้แก้ไข และป้องกันคำตอบโหลดข้อมูลที่มาช้าทับการแก้ไขระหว่างรอ
รายการโปรแกรมต้นทางที่ไม่มีรหัส HIS และ Payor ที่ไม่พบความสัมพันธ์จะมีข้อความแจ้งให้ตรวจสอบ สามารถเพิ่มรายการจาก Master เองได้ แพ็กเกจต้องมีอย่างน้อย 1 รายการตามกติกาเดิม
Location ตามมอคอัพ: ช่องแก้ไขแสดง CODE - NAME เก็บรหัสเดิมเพื่อส่ง HIS ส่วน A4 ช่องใต้ ID / Passport แสดงเฉพาะชื่อ ไม่มีคำว่า Location: ใช้ renderer เดียวกันใน HTML และ PDF
