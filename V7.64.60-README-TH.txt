HealthCheck v7.64.60 — ต่อจากชุด v7.64.59 ที่ผู้ใช้แนบ โดยเก็บฟังก์ชันและ migration เดิมครบ

รายการแก้ไขใหม่
1. URL สำหรับ QR ลูกค้าอยู่ที่ System & API เท่านั้น ผู้ดูแล/ผู้มีสิทธิ์ apiManage จึงอ่านและแก้ค่าได้ทั้งหน้าเว็บและเซิร์ฟเวอร์ ไม่มีปุ่มตั้ง URL ในหน้าคนไข้แล้ว
2. เก็บค่า URL ก่อน–หลัง ผู้แก้และเวลาใน checkup_workflow_audit พร้อม UPDATE ใน transaction เดียว หาก Audit ล้มเหลวไม่บันทึกค่า URL
3. ไม่มีการใช้ request Host เป็น URL ลูกค้าอัตโนมัติ ต้องตั้งค่ากลางหรือ CUSTOMER_PUBLIC_BASE_URL ที่เข้าถึงได้จริง หากไม่มีค่า ให้ติดต่อผู้ดูแลและยังไม่สร้าง QR
4. ตรวจสอบ VisitStatusHIS หน้าคนไข้ใช้ queryHisOpdVisitBatch ตัวเดียวกับ Booking อ่าน opdvisit ด้วย VN และตรวจ HN ให้ตรง ไม่เรียก /checkup/getpatientvisit อีก
5. แสดงชื่อปุ่ม ตรวจสอบ VisitStatusHIS สถานะดิบจาก HIS, VN, เวลาอ่านสำเร็จ, เวลาพยายามตรวจล่าสุด และแหล่ง opdvisit เก็บสถานะสำเร็จเดิมของ HN/VN เดิมเมื่อการตรวจครั้งใหม่ล้มเหลว พร้อมระบุว่าเป็นสถานะเดิม ไม่โชว์ HTML หรือรายละเอียดภายในฐานข้อมูลในหน้าเจ้าหน้าที่
6. ใช้ chargecloseddate เป็นหลักฐานปิดการคิดเงิน ไม่ตีความว่าอ่านสำเร็จเท่ากับชำระเงินแล้ว และไม่ reconcile คำสั่งค้างด้วยสถานะเก่าที่เก็บไว้ หากรหัสสถานะไม่อยู่ใน mapping จะยังเป็น UNKNOWN และรักษาการล็อกเดิม
7. พรีวิว PDF ใช้พื้นที่ viewport ปัจจุบัน ยกเลิก body zoom 110% เฉพาะตอนเปิด ยกเลิก iframe min-height 540px; ปุ่มท้ายหน้าต่างอยู่ในจอที่ browser zoom 100% และรองรับจอเล็ก/แนวนอน
8. เพิ่มสารบัญเอกสารด้านซ้าย กดหัวข้อแล้วไปหน้าหรือจุดนั้นได้ มีปุ่มซ่อน/แสดงสารบัญ มือถือใช้เมนูด้านบน หาก PDF ไม่มี Bookmarks จะแสดงปุ่มเลือกหน้าแทน
9. เอกสารเวียนที่สร้างใหม่มี Thai PDF Bookmarks อิงตำแหน่งจริงหลังจัดหน้า รวมข้อมูลบริษัท ผู้ประสานงาน ช่วงตรวจ โปรแกรมพนักงาน/ครอบครัว เงื่อนไข การเงิน รายงานผล และภาคผนวกตามที่มี เอกสารแนบเพิ่มหัวข้อแยกโดยไม่เปลี่ยนเนื้อหา
10. ปุ่มเอกสารเวียนหน้าคนไข้สร้างพรีวิวจากข้อมูลที่บันทึกและรวมเอกสารแนบแบบอ่านอย่างเดียว จึงมีสารบัญทันที ไม่เขียนทับไฟล์ PDF ประวัติเดิม PDF เก่าที่เปิดโดยตรงมีเมนูเลือกหน้าจนกว่าจะสร้าง PDF ใหม่
11. แพ็กเกจคู่สัญญาที่เลือกแสดง 2 คอลัมน์ ชื่อเด่น รหัสบรรทัดย่อย จำนวนรายการมุมขวา กรอบสูงคงที่ 92px รายการมากเลื่อนภายในได้ จอแคบเป็น 1 คอลัมน์ ไม่เปลี่ยนรายการ/ราคา/ยอดที่บันทึก

เงื่อนไขเดิมยังคงอยู่
QR ใช้คำว่า แพ็กเกจคู่สัญญา อยู่ตำแหน่งเดิมข้างสรุปยอด แสดงหลังยืนยันและตั้ง URL แล้ว ลิงก์หมดอายุหลัง OrderHIS สำเร็จหรือสิ้นวันบริการ ห้ามส่งซ้ำเมื่อไม่ทราบผล HIS แก้ HN/VN/ID ต้องมีเหตุผล ล็อก Order/ChargeClose และการอนุมัติย้อนหลังยังทำงานเดิม ส่ง Order เพิ่มยังปิดไว้จน HIS ยืนยัน API ไม่ส่งของเดิมซ้ำ
