HealthCheck v7.64.68 - Installer Hotfix 1

แอปและฐานข้อมูลใช้เวอร์ชัน v7.64.68 เดิม แก้เฉพาะตัวติดตั้ง:
- แสดง stdout/stderr ของ Deploy ระหว่างทำงาน แทนรอจนขั้น Deploy จบ
- แจ้ง PID และเวลาที่รอทุก 15 วินาที
- แสดงขั้นหยุดระบบ สำรองไฟล์ บีบอัด backup คัดลอก และเริ่มติดตั้งฐานข้อมูล
- ปิด stdin และใช้ NonInteractive เพื่อไม่รอคำถามในหน้าต่างที่ซ่อนอยู่
- ไม่รอ output pipe ของโปรเซสลูกที่ยังเปิดอยู่ตลอดไปหลัง Deploy จบ

หมายเหตุ: แก้การไม่แสดงความคืบหน้า ยังไม่ใช่หลักฐานว่าทุกกรณีที่ติดตั้งนานเกิดจากปัญหาเดียวกัน
ห้ามเปิดตัวติดตั้งซ้ำขณะที่ตัวเดิมยังทำงาน
ไม่ควรบังคับปิดระหว่างสำรองข้อมูลหรือปรับฐานข้อมูล

ทดสอบ: ใช้โปรเซส PowerShell จริงบน Linux ตรวจการแสดง stdout/stderr ก่อนจบงาน,
heartbeat หลัง 15 วินาที, ปิด stdin, drain output สองช่องทาง และรายงาน exit code 7 ถูกต้อง
ตรวจ syntax สคริปต์ PowerShell ทั้งหมดและ SHA256 payload
ยังไม่ได้รันตัวติดตั้งบน Windows จริง
