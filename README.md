# ตัวติดตั้ง v7.64.81

รวมงานที่มีอยู่ใน v7.64.80 และงานเพิ่มเติมที่ตกลงไว้:

1. บันทึกข้อมูลส่วนตัวลูกค้าเฉพาะบุคคล ลดการโหลดข้อมูลทั้งหมด คงตะกร้าและราคาเดิม รองรับตรวจสอบผลเมื่อการเชื่อมต่อขัดข้อง
2. หน้าลูกค้าบนมือถือกระชับขึ้น เว้นขอบ 16 px ลบกล่องเลข 1 ยืนยันตัวตน และจัดตัวเลือกบริษัทให้เต็มความกว้าง
3. พรีวิวหน้าลูกค้าใช้โครงและรูปแบบเดียวกับหน้าจริง สลับคอมพิวเตอร์/โทรศัพท์ 320, 390, 430 px ได้
4. ปุ่มอ่านบัตรเปิดกล้อง สแกนด้านหน้าบัตรด้วย OCR ภายในเครื่อง ตรวจทาน ID/วันเกิดก่อนนำไปกรอก มีทางเลือกอัปโหลดภาพ
5. ปุ่ม ⓘ แสดงความรู้เฉพาะรายการตรวจ จัดการในหน้าแพคเกจคู่สัญญา กรอกเอง/อัปโหลด TXT UTF-8/นำเข้าหลายรายการผ่าน Excel ตามรหัส โดยไม่เปลี่ยนชื่อ ราคา หรือหมวด
6. คงงานเดิม: EMR/Worklist, หมายเหตุเฉพาะบุคคล, สีวางบิล/ชำระเอง, หลายบริษัทและปี, เล่มผลตรวจที่อนุมัติ, โฆษณา/บทความและหน้าตั้งค่าลูกค้า, นัดหมายและตาราง Mobile/Inhouse, ปฏิทินลูกค้าจอง Day/Week/Month
