# HealthCheck v7.64.69 Windows Installer

[ดาวน์โหลดตัวติดตั้ง](https://github.com/manachai22531/Health-Promotion-Smart-Platform/raw/refs/heads/installers/v7.64.69/HealthCheck-v7.64.69-PRODUCTION-WINDOWS-INSTALLER.zip)

แตก ZIP ทั้งหมดในโฟลเดอร์ใหม่ แล้วเปิด **INSTALL-REPAIR.vbs** เพื่อเปิดหน้าต่างตัวติดตั้งหน้าต่างเดียว และอนุญาต UAC ตามปกติ
รอให้ตัวติดตั้งเดิมทำงานเสร็จก่อน ห้ามเปิดติดตั้งซ้อนกัน

รวมการแก้ไขต่อจาก v7.64.68: ตัวเลือกแพทย์/คูปองอาหาร, รูปแบบบริการอื่น,
ยกเลิกตารางโปรแกรม, Excel template/import, PDF ตารางโปรแกรม,
ซ่อนแถบ HIS ก่อนยืนยันการตรวจ และตัวติดตั้ง Hotfix 1/2

ผ่าน build, ชุดทดสอบ 21 รายการ, เบราว์เซอร์/ฐานข้อมูลจริงในการทดสอบ,
การอัปเกรด v7.64.68 -> v7.64.69 และ SHA256
ยังไม่ได้รันตัวติดตั้ง GUI/UAC บน Windows จริง
