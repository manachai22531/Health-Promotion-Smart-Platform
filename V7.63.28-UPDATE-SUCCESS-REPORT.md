# v7.63.28 Update Completion UX

- Adds a minimal, read-only update status endpoint that survives the Production process restart.
- The installer screen continues polling while the old server is stopped and the new server starts.
- A clear success message displays the installed version before the page reloads.
- Failed updates also show an explicit message instead of leaving stale progress on screen.
- Sensitive paths, hashes and backup details are not exposed by the restart-safe status endpoint.
