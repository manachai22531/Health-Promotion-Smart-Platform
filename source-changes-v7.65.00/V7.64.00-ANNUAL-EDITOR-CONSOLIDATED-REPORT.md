# HealthCheckup Smart Search v7.64.00 - Annual Editor Consolidated

Release type: Production Only / Windows ZIP installer

## Scope included

- Full Page annual company editor with sections 00-10 and Attachments.
- Independent Save buttons for sections 00-10 and Attachments; save refreshes the combined PDF preview.
- Draggable middle/PDF column divider with pointer, keyboard arrows, and double-click reset.
- Expanded PDF preview fills the available right-side workspace.
- Section 01 supports one main company and up to 20 subsidiaries. Subsidiaries are numbered 1.1, 1.2, 1.3... in PDF section 1.
- Company contacts are a repeatable block at the end of section 01 (up to 30 contacts).
- Payor Code and Payor Plan use the existing HIS Payor master API; Payor Plan is filtered by the selected Payor Code.
- Terminology changed from "โปรแกรมที่โรงพยาบาล" to "โปรแกรมพนักงาน" in the annual editor and generated circular.
- Section 04 keeps Employee Programs and Family Programs as separate stacked tables.
- Section 09 keeps the editable comparison matrix with yes/grey/blank states and multi-page PDF output.
- Section 10 contains the existing Billing and Cash additional checkup lists.
- Legacy company-year PDF upload is treated as an attachment; legacy bytes are not moved or overwritten.
- Combined document order: circular 00-08 -> section 09 program matrix -> uploaded PDF attachments.
- Duplicate contract-appendix page used previously for subsidiary details is no longer generated.
- Bottom action remains Save and Create Primary Circular; primary PDF history is preserved separately from attachments.
- v7.63.98 Windows installer path/PowerShell startup hotfix remains included.
- Installer dependency preflight now also requires pdf-lib and @pdf-lib/fontkit before it can skip npm ci.
