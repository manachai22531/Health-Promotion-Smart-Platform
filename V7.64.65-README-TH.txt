HealthCheck v7.64.65 — รวมการปรับปรุงจาก v7.64.64

1. ย้ายไอคอนคัดลอกทั้งหมดไปท้ายช่องชิดขวา คงปุ่มคัดลอกแยกรายข้อมูล
2. แถบ Log/VisitStatusHIS/วันที่/ปุ่มเรียงแถวเดียว หากจอแคบเลื่อนแนวนอนภายในแถบ
3. เอาปุ่มสารบัญเอกสารด้านบนออก คง Navigator หัวข้อด้านซ้าย
4. ปุ่มปิด PDF ขนาด 36 x 36 ไม่ยืดตามหัวข้อ
5. ส่งออก/นำเข้า Excel ในมุมขวาของหัวข้อ Order&Station
   ส่งออกทุกรายการที่มี Code เป็นชีต Orders พร้อมชีต Instructions
   แก้ Type, Stations (หลายสถานีคั่นด้วย |), Hidden, Specimen, SortOrder
   ไม่แก้ Code/Name, ไม่สร้าง Order ใหม่, ไม่ลบแถวที่ไม่ได้อยู่ในไฟล์
   คอลัมน์ว่างล้างค่า; คอลัมน์ที่ลบออกจะไม่ถูกแก้
   ตรวจรหัสซ้ำ/ไม่พบ/ชื่อประเภท/สถานี พร้อมตัวอย่างก่อนยืนยัน
   ต้องมีสิทธิ์ orderItemManage, ตรวจ Revision, บันทึกการเปลี่ยนแปลงพร้อม Audit ใน Transaction เดียว
   Specimen เป็นค่ากำหนดใน Order setup ไม่เปลี่ยน Master ที่ HIS
   SortOrder ใช้เรียงภายในกลุ่มสถานีและประเภทเดิม
6. ติดตั้งงาน Windows Task Scheduler: HealthCheck-Production-AutoStart
   เริ่ม 30 วินาทีหลังเปิดเครื่องโดยไม่ต้องล็อกอิน และลองใหม่เมื่อโปรแกรมหยุดผิดปกติ
   นี่เป็น Scheduled Task ไม่ใช่ Windows Service
   ตัวติดตั้งลงทะเบียนให้โดยอัตโนมัติ; เริ่มมีผลรอบเปิดเครื่องถัดไป
   ถ้าต้องลงทะเบียนใหม่ ใช้ ENABLE-AUTOSTART.bat และยืนยันสิทธิ์ Administrator
   ยกเลิก: PowerShell Administrator รัน tools\install-autostart.ps1 -Remove

วิธีติดตั้ง: แตก ZIP ทั้งหมดก่อน แล้วเปิด INSTALL-REPAIR.bat ตามขั้นตอนเดิม
สำรองข้อมูลก่อนอัปเดต ใช้ฐาน Production เดิม คง .env และข้อมูลเดิม
คงชุดแก้ความเร็วจากฐาน v7.64.61 และฟังก์ชันสะสมจาก v7.64.64
ไม่มีการเพิ่ม Dependency หรือ Migration
ไม่ได้ทดสอบบน Windows จริงหรือเชื่อม HIS จริงในสภาพแวดล้อมนี้
