# HealthCheck v7.63.81 — Administrator Password Baseline

## Scope
Production-only update based on v7.63.80. This release changes the built-in `admin` account's legacy default credential to the new administrator credential requested by the system owner.

## Changes
- Updated default administrator password hash used when the `admin` account must be created by the server.
- Added a one-time startup migration for existing installations:
  - If `admin` is missing, it is created with the new default credential.
  - If `admin` still uses the legacy default password hash, it is migrated to the new default.
  - If `admin` already has a custom password, that custom password is preserved.
- Updated `tools/repair-admin.js` to the same one-time migration behavior instead of resetting a customized admin password on every repair/install.
- Updated the browser-side legacy fallback to create a missing admin with the same new hash.
- Removed the old plaintext default password from runtime source files.
- Added `adminPasswordBaselineVersion = v7.63.81` marker in app state so the baseline migration is not repeatedly applied.

## Compatibility
- Production only: `APP_ENV=production`
- Production port: `3000`
- Update Center root files retained: `server.js`, `package.json`, `VERSION.txt`, `INSTALL-REPAIR.bat`
- Existing v7.63.80 mapped HIS User Sync behavior remains covered by release regression tests.

## Security note
The distributable runtime stores only the deterministic application password hash for the default administrator credential; the new plaintext password is not embedded in runtime source files.
