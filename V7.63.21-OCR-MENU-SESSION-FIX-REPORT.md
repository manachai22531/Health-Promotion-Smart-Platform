# v7.63.21 OCR Menu Session Fix

## Problem

After a Production restart or update, the browser could restore a staff user from session storage even though the secure server session no longer existed. Opening OCR Document was then redirected to the home page and appeared to do nothing.

## Fix

- The application now accepts authentication only from `/api/auth/session`.
- A stale browser session marker is cleared instead of being used as authentication.
- OCR Document verifies the server session immediately before navigation.
- If the session expired, the login screen is shown with a clear message instead of silently returning to the home page.
- Existing OCR permission checks and protected server routes remain enabled.
