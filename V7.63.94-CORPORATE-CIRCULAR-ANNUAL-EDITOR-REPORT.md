# HealthCheck v7.63.94 (Production Only)

## Changes
- Edit Year form reorganized to mirror the provided Corporate circular, in exact sections **00, 01, 02, 03, 04, 05, 06, 07, 08**.
- Original annual company settings preserved and moved into matching sections.
- Annual date range, report condition, and sales name/telephone provide the canonical values used by the PDF, avoiding duplicate fields.
- HIS add-on package rows have a per-row mapping for hospital, family, or omitted from the generated circular. Category is saved with each package in relational `company_years.source_data` JSONB.
- Additional PDF-only hospital/family programs remain supported through expandable extra fields.
- Separate company PDF attachment, Corporate circular PDF preview/download, and PostgreSQL per-year circular metadata preserved.
- Existing Production Only enforcement, Windows installer scripts and Update Center retained.

## Cautions
- The standard PDF is based on the user-supplied A4 form, and must be checked with a real Thai font on the Windows Server.
- Installation and live database updates have **not** been exercised on a real hospital Production server. Back up PostgreSQL before applying.
- Preview works for years that have already been saved. For a new year, save once first.
