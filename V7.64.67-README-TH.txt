HealthCheck v7.64.67 — รวมรายการจาก v7.64.66 และสิ่งที่คุยล่าสุด

เมาส์และเอฟเฟกต์
- ตัดตัวเลือกมาตรฐานออก คง มือ 3D / มินิมอล / คลินิก
- เพิ่ม คทาปลายดาว 3D / อุ้งเท้าแมว 3D / ปลากระโทงร่ม 3D รวม 6 แบบ
- ปรับสีหลักได้ด้วย Color Picker, รหัส HEX 6 หลัก, สีสำเร็จรูป หรือใช้สีเดิม
- เลือกขนาด เล็ก/กลาง/ใหญ่ และจำค่าในเบราว์เซอร์นี้
- ดาวตามเมาส์ เปิด/ปิด แสดงเมื่อขยับ หรือกดค้างแล้วลาก
- เลือกสีและจำนวนดาวได้ ค่าเริ่มต้นปิด
- จำกัดดาวไม่เกิน 40 อนุภาค ใช้ Canvas เดียว จำกัดด้านยาวไม่เกิน 1280px
- ลบ Canvas และหยุด animation เมื่อดาวจางหมด/ปิด/ซ่อนแท็บ ไม่จับ mousemove เพื่อสร้าง DOM ต่อเนื่อง
- ไม่กีดขวางการคลิก ช่องพิมพ์และปุ่มที่กดไม่ได้ใช้เมาส์ตามสถานะเดิม

ลดหน่วยความจำส่วนที่เกินจำเป็น
- SPA ขอ /api/his-packages?compact=1 คงรายละเอียดแพ็กเกจ แต่ไม่ส่ง source_data ดิบซ้ำมาเก็บในเบราว์เซอร์
- API เดิมเมื่อไม่ส่ง compact ยังคงข้อมูลดิบตามเดิม
- คำขอโหลดแพ็กเกจพร้อมกันใช้ request เดียว; หลังแก้ไข/ซิงก์ใช้ force refresh
- ป้องกัน response เก่าเขียนทับข้อมูลที่โหลดใหม่กว่า
- ไม่สร้างตาราง Package/Booking/Company ที่ยังไม่เปิดจากตัวโหลดเบื้องหลัง
- ยังมีการโหลด app state และรายละเอียดแพ็กเกจทั้งแคตตาล็อกตามโครงสร้างเดิม
- ไม่รับประกันว่าแท็บจริง 595 MB จะเหลือเท่าใด ต้องวัดกับฐานข้อมูลและการใช้งานจริงหลังอัปเดต
