🖨 HealthCheck Scan Agent

Scan Agent: แบบ TWAIN Memory x86 สำหรับ Kyocera ECOSYS / ADF-Feeder · ไม่ Compile ที่เครื่อง User · ไม่ดาวน์โหลด NuGet · ไม่ต้องใช้อินเทอร์เน็ต · ไม่สลับไป WIA อัตโนมัติสำหรับ Kyocera
  1. กด ดาวน์โหลด Scan Agent ด้านล่าง แล้วแตก ZIP ให้เรียบร้อย
  2. ดับเบิลคลิก INSTALL-SCAN-AGENT.cmd หนึ่งครั้ง (ติดตั้งทับรุ่นเดิมได้ และไม่ต้องใช้ Administrator)
  3. ใช้ TEST-TWAIN-SOURCES.cmd เพื่อตรวจว่าเห็น Source Kyocera / Scan / ECOSYS M2640idw
  4. กลับมาหน้านี้แล้วกด Scan Scanner · ADF หลายหน้าจะเข้า OCR Batch Queue อัตโนมัติ
⬇ ดาวน์โหลด Scan Agent v7.63.53 TWAIN Memoryคู่มือติดตั้ง
TWAIN Source ชื่อ Scan จะถูกเลือกอัตโนมัติ · ใช้ Memory Transfer เป็นหลัก · ไม่สลับไป WIA อัตโนมัติสำหรับ Kyocera
