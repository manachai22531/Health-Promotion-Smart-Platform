HealthCheck v7.64.64 — รวมงานต่อจาก v7.64.63 และรักษาฐาน performance v7.64.61

แถบปุ่มตามมอคอัพล่าสุด
- ย้าย VisitStatusHIS จากด้านบนไปแถวล่างชิดซ้าย วันที่ตรวจล่าสุดอยู่ต่อท้ายปุ่มในบรรทัดเดียวกันเมื่อพื้นที่พอ
- กดปุ่มสถานะเพื่อตรวจใหม่ได้ ลบปุ่มตรวจสอบ VisitStatusHIS ที่ซ้ำ
- ส่ง Order เพิ่ม อยู่ต่อหลัง OrderHIS แต่ยังปิดใช้งาน เพราะยังไม่มี API ที่รับรองการส่งเพิ่ม จึงไม่ส่งรายการเดิมซ้ำ
- ย้ายยกเลิกการยืนยัน/ขอแก้ย้อนหลัง/อนุมัติ/รีเฟรชสิทธิ์ลงแถวเดียวกับสถานะ ตามสิทธิ์และเงื่อนไขเดิม
- ปุ่มปิดอยู่ขวาฝั่งกรอกข้อมูล ปุ่มพิมพ์อยู่ฝั่งสรุป จอแคบขึ้นแถวได้ ไม่ตัดปุ่มสำคัญ

คลิกคัดลอก
- ข้อมูลที่แสดงในตารางผู้รับบริการ สิทธิ์หน่วยงาน และคอลัมน์รหัสแพ็กเกจ คลิกคัดลอกได้ มีไอคอนและข้อความคัดลอกแล้ว
- ช่องหลายข้อมูลแยกเป้าหมายคลิก เช่น วันเกิด / อายุ / เพศ; อายุคัดลอกเฉพาะตัวเลข
- มีไอคอนคัดลอกทั้งหมดท้ายช่อง ใช้กับสัญชาติ/สถานภาพ ตำแหน่ง/รหัสพนักงาน Payor/Agreement และ Office/Location ด้วย
- คัดลอกเฉพาะข้อความที่ผู้ใช้เห็น ไม่อ่านข้อมูลซ่อนหรือเพิ่มสิทธิ์ดูข้อมูลส่วนบุคคล
- คลิกคัดลอกไม่เปิดรายละเอียดเคส และยังทำงานหลังชื่อสิทธิ์ถูกโหลดมาแทน code

Level
- ซ่อนแถบ/ปุ่มและข้อความ EXP เมื่อ Role ไม่ได้เปิดหรือไม่มีงานที่รับ EXP ได้ รวมถึงตอนยังอ่านสิทธิ์ไม่สำเร็จ
- Admin ยังเห็น Level เสมอ ปรับ Role ของผู้ใช้เดิมแล้วล้างสถานะสิทธิ์เก่าก่อนอ่านใหม่
- ไม่ลบ EXP เดิมหรือเปลี่ยนกติกาสะสมบนเซิร์ฟเวอร์

สีระยะเวลาตรวจ
- แดงอ่อน: เลยวันสิ้นสุด
- ส้มอ่อน: เหลือไม่เกินหนึ่งเดือนปฏิทิน รวมวันสุดท้าย
- เขียวอ่อน: อยู่ระหว่างดิวและเหลือเกินหนึ่งเดือน
- ฟ้าอ่อน: ยังไม่ถึงวันเริ่ม
- เทาอ่อน: ยังไม่กำหนดวันที่
- เหลือไม่เกิน 7 วันเพิ่มข้อความใกล้หมดดิวและเน้นตัวหนา สีมีข้อความกำกับ คำนวณวันปัจจุบันตามเวลาไทยและรองรับปลายเดือน
