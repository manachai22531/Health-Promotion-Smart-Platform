# v7.63.60 — OCR Menu Click Fix

## Root cause
`openOcrViewSecure()` correctly called `showView('ocrView', { ocrSessionVerified: true })`, but two later compatibility wrappers redefined `showView(id)` without forwarding the second `options` argument.

That removed `ocrSessionVerified:true`. The base `showView()` therefore treated the OCR request as unverified and called `openOcrViewSecure()` again. This recursive loop happened before the OCR workspace could become active, so clicking the OCR icon appeared to do nothing.

## Fix
- Forward `options` through the responsive `showView` wrapper.
- Forward `options` through the Organization Book compatibility `showView` wrapper.
- Keep immediate OCR workspace opening and background session validation.
- No changes to the A4 summary screen.

## Regression guard
Added `release-candidate-v76360-ocr-menu-options-forward.test.js` to ensure future wrappers cannot silently drop OCR navigation options again.
