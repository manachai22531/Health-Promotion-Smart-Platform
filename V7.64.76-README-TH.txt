HealthCheck v7.64.76 — Windows Production Installer
รวมงานถึง v7.64.75 พร้อมหมายเหตุรายบุคคลและแก้ปุ่มตามธีม 6 กลุ่ม

วิธีติดตั้ง
1. ตรวจว่าไม่มีตัวติดตั้ง/Update Center อื่นกำลังทำงาน และมีพื้นที่ว่างไดรฟ์ D: เพียงพอ
2. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ ห้ามรันไฟล์จากภายใน ZIP
3. เปิด INSTALL-REPAIR.vbs และอนุญาต UAC
4. รอ Complete SUCCESS ตรวจเวอร์ชัน v7.64.76 แล้วกด Ctrl+F5
เป้าหมาย D:\HealthCheck\Production / Port 3000 / DB health_check_smart_search
สำรอง Source และฐานข้อมูลก่อนเปลี่ยนระบบ และรักษา .env / ค่าระบบ / ข้อมูลเดิม
อย่าลบ Production/data หรือไฟล์ฐานข้อมูลเพื่อเพิ่มพื้นที่ว่าง

กรณี Update Center รุ่นเก่าแจ้ง Production health/version preflight failed
เปิด REPAIR-UPDATE-CENTER.vbs จากชุดนี้ก่อน แล้วอัปโหลด ZIP ใหม่ หรือใช้ INSTALL-REPAIR.vbs โดยตรง
ห้ามรันตัวติดตั้งและ Update Center ซ้อนกัน

หมายเหตุเฉพาะบุคคล
- หน้าค้นหา: แสดงใต้เงื่อนไขการรายงานผล/เจ้าหน้าที่ขาย
- หน้ารับบริการ/เลือกแพ็กเกจ: แสดงและแก้ไขในกรอบซ้ายของยอดรวม
- บันทึกได้ทั้งปุ่ม บันทึกหมายเหตุ และ บันทึกข้อมูล ด้านล่าง
- ทุกหน้าดึงจากหมายเหตุเดียวกัน แยกตามบุคคลและบริษัท/ปี
- ผู้มีสิทธิ์ customerEdit / receiveEdit และ admin แก้ไขได้ ผู้ดูข้อมูลอย่างเดียวอ่านได้
- ตรวจการแก้ไขพร้อมกันก่อนบันทึก และเก็บประวัติผู้แก้ไข
- ข้อความภายในเจ้าหน้าที่ ไม่เพิ่มลงข้อมูลหน้าลูกค้าสาธารณะ

นำเข้า / ดูข้อมูลทั้งหมด
- เทมเพลตทั้งสองไฟล์เพิ่มคอลัมน์ หมายเหตุเฉพาะบุคคล (ไม่เกิน 2,000 ตัวอักษร รองรับหลายบรรทัด)
- รองรับหัว หมายเหตุ / หมายเหตุเฉพาะบุคคล / Note / Notes / Remark / Remarks / PersonalNote
- คอลัมน์ หมายเหตุ Template เป็นคำแนะนำ ไม่ใช่หมายเหตุของผู้รับบริการ
- นำเข้าซ้ำโดยไม่มีคอลัมน์หมายเหตุหรือเว้นว่าง จะเก็บหมายเหตุเดิมไว้
- ต้องการล้างข้อความ: ล้างในช่องหมายเหตุ แล้วกดบันทึกหมายเหตุ
- แสดงในตัวอย่างนำเข้า ตาราง ดูข้อมูลทั้งหมด และ Excel ส่งออก
- ตารางผู้ใช้ที่เคยเลือกคอลัมน์ไว้จะเพิ่มคอลัมน์หมายเหตุให้ครั้งแรก หลังจากนั้นซ่อน/แสดงได้ตามเดิม

แก้ปุ่มที่ไม่เข้าธีม
1. เอกสารเวียน หัวข้อ 12: ปุ่ม × ลบโปรแกรม/รายการตรวจ ใช้ปุ่มลบแบบย่อของระบบ
2. หน้าลูกค้า: เพิ่มลงตะกร้า แท็บประเภทแพ็กเกจ และปุ่มหลัก ตามสีแบรนด์ที่ตั้งค่า
3. หน้าลูกค้า: เมนู เลือกแพ็กเกจ / เล่มผลตรวจ / นัดหมาย ตามสีแบรนด์เดียวกัน
4. Worklist: แท็บกรองสถานะตามธีม Current / Premium / Warm
5. ผู้ใช้งานและสิทธิ์: แท็บหลักตามธีม Current / Premium / Warm
6. /customer-setup: รับธีมเจ้าหน้าที่จากหน้าหลัก และปรับตามเมื่อเปลี่ยนธีมอีกหน้าต่าง
สีลบ/ยกเลิก สีสถานะ ไอคอนหมวด และโล่เลเวลคงความหมายเดิม
หน้าลูกค้าสาธารณะใช้สีแบรนด์ที่กำหนดใน ตั้งค่าหน้าลูกค้า

งานเดิมยังรวมอยู่
- หน้าลูกค้าแบบตาราง เลือกบริษัท/ปี เล่มผลตรวจเฉพาะเจ้าของและเฉพาะ VN ที่แพทย์อนุมัติ
- นัดออกหน่วยจำกัดบริษัท นัดโรงพยาบาลใช้โควตาร่วมกัน จอง/เลื่อน/ยกเลิกตามตารางที่สร้างในระบบ
- เปิดรับนัด: กำหนดช่วงสิทธิ์และเปิดโครงการ แล้วไป นัดหมาย HIS > จัดการตารางรับนัดลูกค้า
- Role อื่นที่จัดตารางต้องมี appointmentView และ appointmentScheduleManage
- EMR แบบตาราง วันที่วันนี้ รีวิว/พิมพ์เล่ม และหน้าตั้งค่าลูกค้าแยกสำหรับการตลาด
- ปุ่มโล่ EXP หน้าชื่อผู้ใช้ ปุ่มค้นหาเรียงระดับเดียวกัน ระบบความปลอดภัยตาม Role
- งานบริษัท เอกสาร Excel/PDF, Payor, ประวัติ Login และการซ่อมตัวติดตั้ง/Update Center เดิม
