HealthCheck v7.65.07 Production Windows Installer

รวมความสามารถและการแก้ไขทั้งหมดจาก v7.65.06 พร้อมรายการต่อไปนี้

1. หน้าค้นหาลูกค้ามีรูปแบบแสดงผล 2 แบบ: การ์ดเดิมที่เก็บรายละเอียดและหัวข้อเดิมครบ และตารางรายการสำหรับตรวจหลายรายชื่อได้เร็วขึ้น
2. โหมดตารางเลือกทำงานได้ครั้งละ 1 รายการด้วย radio เท่านั้น แถวที่เลือกมีสีเน้นและชื่อผู้ถูกเลือกแสดงบนแถบคำสั่ง
3. ย้ายคำสั่งรายบุคคลออกจากแต่ละแถวมาไว้เหนือหัวตาราง และแสดงครบ: รายละเอียด, แก้ไขข้อมูล, ยืนยันการตรวจ, เปิดหน้าลูกค้า, ดูนัดหมาย, ดูเล่ม และเอกสารเวียน
4. ปุ่มคำสั่งถูกปิดก่อนเลือกรายการ และตรวจสิทธิ์ Role เดิมของแต่ละฟังก์ชันก่อนเปิดใช้ ไม่มีการข้ามสิทธิ์จากโหมดตาราง
5. นำข้อความจำนวนผลลัพธ์ออกจากแถบค้นหา และจำรูปแบบการแสดงผลล่าสุดไว้ในเครื่องผู้ใช้
6. คอลัมน์ประเภทในตารางแพ็กเกจการ์ดเดิมแคบลง และข้อความประเภทเป็นตัวหนาเพื่ออ่านง่ายขึ้น
7. หน้า Role แสดงสิทธิ์ Package HIS ที่ใช้งานจริงครบอีก 2 รายการ: ดูสถานีของรายการในแพ็กเกจ และกำหนดสถานีของรายการในแพ็กเกจ
8. เพิ่มการทดสอบ permission coverage ป้องกันชื่อสิทธิ์ที่ใช้งานจริง รายการกลาง และช่องตั้งค่า Role ไม่ตรงกัน ปัจจุบันผ่าน 95/95 สิทธิ์
9. การ์ดสุขภาพระบบเดิมยังแสดงในศูนย์ตรวจประสิทธิภาพ พร้อมแดชบอร์ดข้อมูลจริงและ Export สำหรับ Dev จาก v7.65.06

ตัวติดตั้งรักษา .env, API key, การเชื่อมต่อฐานข้อมูล และข้อมูลเดิม ใช้กลไก backup, integrity check, migration, health check และ rollback ของ Production Installer เดิม

ติดตั้ง: แตก ZIP ทั้งหมด แล้วเปิด INSTALL-REPAIR.bat ด้วย Run as Administrator
เป้าหมายมาตรฐาน: D:\HealthCheck\Production, port 3000, database health_check_smart_search

ข้อจำกัดจากการตรวจสิทธิ์: หน้า Role และชื่อสิทธิ์ครบ 95/95 แต่ API รุ่นเก่าบางกลุ่มยังพึ่ง local/LAN guard มากกว่า Role guard ฝั่ง Server รายละเอียดอยู่ใน PERMISSION-AUDIT-v7.65.07.md
