# HealthCheck v7.64.27 PRODUCTION — Advanced appearance settings

## Changes
- Fixed Premium-theme user/session text contrast in the light top-bar pill.
- Added Small, Medium, and Large cursor sizes.
- Added Standard, 3D Hand, Minimal, and Clinic cursor styles; 3D Hand remains the migration default.
- Added Gold Classic, Ice Blue, and Premium Violet global sparkle palettes.
- Added Soft, Crystal, and Digital click-sound profiles with preview controls.
- Expanded the unified person-and-palette settings panel and retained UI density, theme, effect, and sound toggles.

## Compatibility
- Existing theme, UI-density, sound on/off, and effect on/off preferences are preserved.
- Users without a cursor preference continue with the original 3D Hand cursor.
- Sparkles remain pointer-accurate under UI scale/density and use 6–10 stars, 20–45 px distance, and 0.5–0.8 second duration.
