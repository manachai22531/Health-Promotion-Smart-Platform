## Important limitations

**A package named PRODUCTION is not a certification of production readiness.** This environment did not have the npm PDF dependencies available and could not install them from its registry, so actual Node `pdf-lib` output, PDF merge, live PostgreSQL, Windows upgrade, service restart, rollback and Update Center end-to-end behaviour were **not tested**. Validate all of those on a non-live machine before upgrading the hospital server.

Section 01 PDF design intentionally places a separate register page (or pages for many subsidiaries) before the original corporate circular template; it does not reproduce all of the example PDF in one page.

Installer execution performs backups and database migrations, and may restart the Production server. Always ensure free disk space, take an external verified PostgreSQL backup, and preserve the prior release ZIP/restore plan.
