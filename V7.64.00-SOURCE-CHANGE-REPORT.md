# HealthCheckup Smart Search v7.64.00 — source change report

## Delivered

- Added per-company/year, per-section PATCH APIs for annual sections 00–10. These update only the selected company array and circular memo keys; section saves do not send the global records/state payload and do not call `renderAll()`.
- Added section-save buttons with incremental preview refresh. Attachment/primary-document metadata is cached for 60 seconds and invalidated after upload, delete, or primary PDF generation.
- Preserved the full-page annual editor and draggable form/PDF workspace; expanded the right PDF preview height.
- Kept subsidiaries and now labels them 1.1, 1.2, 1.3… in generated PDF output.
- Added multiple company coordinators at the end of section 01.
- Connected annual Payor Code and dependent Payor Plan lists to the same HIS master endpoints used by Booking.
- Replaced the user-facing/PDF term “โปรแกรมที่โรงพยาบาล” with “โปรแกรมพนักงาน”.
- Added section 09 for employee/family program tables and section 10 for additional billing/cash examinations while retaining the original 00–08 flow.
- Primary PDF generation now creates the circular first, then appends the preserved legacy PDF and uploaded attachments in database order. Byte-identical attachment files are included once.
- Existing attachment upload/storage endpoints and original legacy PDFs are retained.
- Existing Worklist layout (Refresh beside Search, single filter row, narrow pending-confirmation rail, full-column Today’s Cases table) and two-row customer search layout are retained.
- Production-only runtime, PostgreSQL storage, Update Center files, compatibility installers, and hotfix files were not removed.

## Remaining validation / limitations

- Run database-backed UAT against a PostgreSQL copy before production rollout, especially concurrent annual-section editing and large/encrypted attachment PDFs.

- No installer, ZIP, update manifest, or release package was created in this work.
