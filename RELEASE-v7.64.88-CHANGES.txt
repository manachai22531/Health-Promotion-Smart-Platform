HealthCheck v7.64.88 — Windows Production Installer / Update Center Package
รุ่นต่อจาก v7.64.87 โดยใช้ ZIP ต้นฉบับที่ผู้ใช้ส่งมาเป็นฐาน

สิ่งที่เพิ่ม
- เลือกลบหลายบริษัท/ปี พร้อมตรวจรายการ ระบุเหตุผล และพิมพ์ข้อความยืนยัน
- สำรองข้อมูลใน transaction เดียวกับการลบ หากผิดพลาดยกเลิกทั้งชุด
- ป้องกันรายการที่มีงานตรวจ, EMR, ประวัติคำสั่ง HIS หรือ Booking ไม่กระทบปีที่ไม่ได้เลือก
- ดูประวัติไฟล์นำเข้าแบบรายบริษัทหรือทั้งหมด ค้นหา ดูตัวอย่างทุกชีต และดาวน์โหลดต้นฉบับ
- เก็บประวัติไฟล์ทุกครั้งตั้งแต่รุ่นนี้ รวมไฟล์ล่าสุดที่ระบบเดิมยังมีอยู่
- ไฟล์เก่าที่ระบบเดิมเขียนทับแล้วไม่สามารถกู้คืนได้
- คงระบบสิทธิ์ผู้ใช้ อายุรหัสผ่าน idle timeout และฟังก์ชันของ v7.64.87

ติดตั้ง / อัปเกรดจาก v7.64.87
1. แตก ZIP ทั้งหมดไปยังโฟลเดอร์แยก เช่น D:\HC76488 ห้ามรันจากใน ZIP
2. คลิกขวา INSTALL-REPAIR.bat แล้วเลือก Run as administrator
3. ทำตามหน้าจอและรอจน health check ผ่าน แสดงเวอร์ชัน v7.64.88
4. เปิดหน้าโปรแกรมแล้วกด Ctrl+F5
ปลายทางเดิม D:\HealthCheck\Production, port 3000, DB health_check_smart_search
ตัวติดตั้งเดิมมีขั้นตอนสำรอง Source/Database และรักษา .env/API keys/การเชื่อมต่อเดิม
แพ็กเกจเดียวกันใช้กับ Update Center ที่รองรับ ZIP เดิมได้ โดยต้องตรวจความพร้อมผ่านก่อน
มีการป้องกันติดตั้งทับรุ่นที่ใหม่กว่า 7.64.88

ตรวจ SHA256 ของ ZIP ด้วยไฟล์ .sha256 ที่แนบ
ตัวติดตั้งตรวจ SOURCE-MANIFEST-SHA256.txt ก่อนดำเนินการ
