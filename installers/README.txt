OPTIONAL OFFLINE / 403 FALLBACK

Normally you do not need to put anything in this folder.

If PostgreSQL automatic download is blocked by HTTP 403:
1. Download the official PostgreSQL 17 Windows x64 installer from:
   https://www.postgresql.org/download/windows/
2. Put the downloaded postgresql-17*-windows-x64.exe file in this folder.
3. Run INSTALL-REPAIR.bat again as Administrator.

The installer will detect the EXE automatically and install PostgreSQL using the password and port you enter.
