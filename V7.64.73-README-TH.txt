HealthCheck v7.64.73 — Windows Production Installer
รวมงานทั้งหมดถึงม็อกอัปที่ยืนยันล่าสุด 23 ตุลาคม 2026

ติดตั้งโดยตรง (แนะนำสำหรับเครื่องที่เคยติด Update Center รุ่นเก่า)
1. ปิดตัวติดตั้ง/ตัวอัปเดตเดิมที่สิ้นสุดแล้ว ห้ามเปิดงานติดตั้งซ้อนกัน
2. ตรวจพื้นที่ว่าง D: หากไม่พอ ย้าย ZIP สำรองเก่าที่ต้องเก็บไปไดรฟ์อื่น
   ห้ามลบ Production/data, .env หรือฐานข้อมูล PostgreSQL
3. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ แล้วเปิด INSTALL-REPAIR.vbs และอนุญาต UAC
4. รอ Complete SUCCESS ตรวจเวอร์ชัน v7.64.73 แล้วกด Ctrl+F5
เป้าหมาย D:\HealthCheck\Production / port 3000 / health_check_smart_search
รักษา .env/การเชื่อมต่อ/ค่าระบบเดิม และสำรอง Source กับฐานข้อมูลก่อนอัปเกรด

หากต้องการใช้ Update Center บน v7.64.68 ที่ยังมีปัญหา preflight
- แตก ZIP แล้วเปิด REPAIR-UPDATE-CENTER.vbs หนึ่งครั้งก่อน
- ตัวซ่อมตรวจ hash สำรอง helper เดิม และปฏิเสธเมื่อมีงานอัปเดตกำลังทำงาน
- จากนั้น Upload ZIP ใหม่ แล้ว Preflight/Install ตามลำดับ
- การ Upload ZIP อย่างเดียวไม่ซ่อม helper เก่าที่ทำงานก่อน deploy ได้

หน้าจอตามม็อกอัปล่าสุด
- EMR เป็นตารางรวมเต็มพื้นที่ มีผู้ป่วย/HN/VN บริษัท/โครงการ วันที่ส่งตรวจ
  แพทย์ สถานะ ผลครบ/ทั้งหมด และปุ่มรับ EMR/ทำเล่มหรือเปิดเล่มในแต่ละแถว
- เปิดเล่มเต็มพื้นที่และกลับตารางได้ คงตัวกรองวันที่/แพทย์/สถานะ/ค้นหา
  รวมทั้งการบันทึกแบบร่าง อนุมัติ และแปลผลเดิม
- Worklist ตารางเดียวรวมรอยืนยัน รอเปิด Visit รอสั่ง Order ส่งตรวจและเสร็จสิ้น
  ลบกล่องสรุป 4 ช่องและหัวข้อ TODAY'S SERVICE BOARD / รายการรับบริการวันนี้
  ตามกรอบแดง คงแถบกรองและจำนวนรายการ
- งานกลุ่มใช้เฉพาะเคสมี Order สำเร็จ HN/VN ไม่ยืนยันหรือสร้าง Visit ให้อัตโนมัติ
- หน้าค้นหาลบหัวข้อ CUSTOMER SEARCH/ค้นหาผู้รับบริการ ข้อความแนะนำการค้นหา
  และคำว่า ค้นหาจาก PostgreSQL คงจำนวนผลลัพธ์
- ลบหัวข้ออัปเดต/ยืนยันการตรวจแล้วบนแถบด้านขวา คงจำนวนวันนี้และรายชื่อเคส
- ปุ่มข้อมูลบริษัทอยู่แถวค้นหา ลดพื้นที่ว่าง เมนูไม่ล้นจอเล็ก
  แผงชื่อ/HN/VN ปรับขนาดให้อยู่ในพื้นที่ข้อมูลลูกค้า

รวมงานก่อนหน้า v7.64.68–72
- บันทึกแยกหัวข้อ 02/03/04 เพิ่มบริษัทใหม่พร้อมปี สลับ 00/01 ในฟอร์ม
  โดยลำดับเนื้อหา PDF คงเดิม
- Password Expired และ Idle Logout ค่าเริ่มต้น 15 นาที ปรับตาม Role
  บังคับฝั่ง server และแบ่งปันกิจกรรมผู้ใช้ระหว่างแท็บ
- แผงตั้งค่าไม่ตัดปุ่ม และประกายดาวตรงตำแหน่งเมาส์
- ตรวจแบบไม่ฟังผล ไม่มีคูปองอาหาร และ free text รูปแบบบริการอื่นแทน Walk in
- ยกเลิกตารางโปรแกรม เทมเพลต/นำเข้า Excel และแนบ PDF ตารางโปรแกรม
- ซ่อนแถบ HIS จนยืนยันการตรวจ แพ็กเกจคู่สัญญาที่เลือกขยายเต็มพื้นที่
- Master Payor/Plan แยกตามบริษัทในเครือ และประวัติ Login ใน Operations Center
- ตัวติดตั้งหน้าต่างเดียว live log/heartbeat และแก้ health/version preflight

การแก้พื้นที่ดิสก์ไม่พอของตัวติดตั้ง
- Source สำรองลง ZIP โดยตรง ไม่ทำสำเนา Source ทั้งชุดไป temp ก่อน
- ตรวจขนาด/พื้นที่ว่างก่อนสั่งหยุดแอป และตรวจซ้ำกับ snapshot หลังหยุด
- ประเมินขั้นต่ำขนาด Source เผื่อ ZIP overhead + payload + 1 GiB
  งาน DB backup/ติดตั้ง dependencies อาจต้องใช้พื้นที่มากกว่านี้
- เก็บ hidden configuration/.env และ data/uploads ไม่ข้ามข้อมูลจริง
- ไม่รวมโฟลเดอร์ระดับราก node_modules/logs/backups/tmp/updates/.git
- แสดงความคืบหน้าขณะเขียน ZIP ตรวจรายการ/ขนาดก่อนเผยแพร่ ZIP สำเร็จ
- ลบเฉพาะ partial ZIP ที่สร้างเองเมื่อสำรองล้มเหลว ไม่ลบ backup เก่าอัตโนมัติ
- ถ้าสำรองล้มเหลวหลังหยุดแอป จะพยายามเปิดแอปเดิมและแสดงผล launcher
- การสำรองฐานข้อมูลยังเป็นขั้นตอนบังคับและอาจใช้เวลาตามขนาดข้อมูล

ยังไม่ได้รันตัวติดตั้งเต็มขั้นตอนผ่าน Windows GUI/UAC/Robocopy/Task Scheduler จริง
