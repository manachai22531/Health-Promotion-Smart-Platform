HealthCheck v7.64.68 — Windows Production Installer
ต่อจาก v7.64.67 รวมการแก้ไขที่ตกลงในบทสนทนา

1. บริษัทและเอกสารเวียน
- เพิ่มบริษัทใหม่พร้อมปี และกดบันทึกได้จากหน้าเดียว ไม่ต้องเซตอัพแยกก่อน
- แสดงช่องปีตรวจสุขภาพ รหัสบริษัทเดิมใช้ต่อเมื่อเพิ่มปี และตรวจปีซ้ำ
- หน้ากรอกเรียง 00 ข้อมูลบริษัท > 01 ข้อมูลหัวหนังสือ > 02–13
- ปุ่มบันทึก 02 บริษัทในเครือ / 03 ผู้ประสานงาน / 04 จำนวนพนักงาน ครบ
  บันทึกเฉพาะข้อมูลส่วนที่เลือก โดยไม่ทับค่าที่บันทึกไว้ของหัวข้ออื่น
- รูปแบบและลำดับเอกสาร PDF เดิม ไม่เปลี่ยนตามลำดับหน้ากรอก

2. หน้าตาและเมาส์
- แผงตั้งค่าพอดีพื้นที่จอแม้ UI zoom 110%; หัวแผงและปุ่มบันทึกมองเห็นเสมอ
- เลื่อนเฉพาะรายการตั้งค่า รองรับจอเตี้ย/หน้าจอแคบ
- ดาวตามเมาส์เริ่มตรงปลายเมาส์ ชดเชย UI zoom/ขนาด canvas และการเลื่อนหน้า

3. การเข้าใช้งาน
- Login/Logout ผ่าน Session ฝั่ง Server
- รหัสผ่านใหม่/รีเซ็ต อย่างน้อย 10 ตัว มีตัวอักษรและตัวเลข
- Password expired ค่าเริ่มต้น 90 วัน กำหนดแยกตาม Role ได้ 1–365 วัน
- ไม่ใช้งาน 15 นาทีออกจากระบบ กำหนดแยกตาม Role ได้ 1–1440 นาที
- เมาส์/คีย์บอร์ด/การเลื่อนจากผู้ใช้จริงต่อเวลา; polling ไม่ต่อเวลา
- เปิดหลายแท็บได้; Remember login ไม่ข้ามกฎ idle
- ตั้งค่าที่ ผู้ใช้ & สิทธิ์ > Role > เลือก Role >
  กำหนดสิทธิ์และความปลอดภัยของ Role ที่เลือก > บันทึกนโยบาย Role
- ผู้แก้ต้องมี permissionManage; ใช้กับ Role admin และ Doctor ได้
- รหัสหมดอายุต้องยืนยันรหัสเดิมและตั้งรหัสใหม่ก่อนใช้งานต่อ
- บัญชีเดิมนับอายุจาก passwordChangedAt / passwordResetAt / firstLoginAt / createdAt
  ถ้าไม่มีวันที่ที่ใช้ได้ จะให้เปลี่ยนรหัสในการเข้าสู่ระบบครั้งถัดไป
- บัญชี admin ที่สร้างใหม่บังคับเปลี่ยนรหัสครั้งแรก; รหัสผ่านที่ผู้ใช้ตั้งเองเดิมคงไว้
- กลไกกู้คืนรหัสและอัลกอริทึม hash เดิมไม่ได้ถูกออกแบบใหม่ในรุ่นนี้

4. ตัวติดตั้ง
- ใช้ Windows installer GUI/worker ต่อจากแพ็กเกจ v7.64.67
- ติดตั้ง/อัปเกรดที่ D:\HealthCheck\Production พอร์ต 3000
  PostgreSQL database health_check_smart_search (ต้องมี Drive D:)
- สำรอง Source และฐานข้อมูลก่อนอัปเกรด; หยุดการติดตั้งเมื่อ backup ล้มเหลว
- คงไฟล์ .env, API keys, การเชื่อมต่อฐานข้อมูล และข้อมูลเดิม
- ตรวจ SHA256 ของไฟล์ payload ก่อนเริ่มติดตั้ง
- ตรวจ dependency ที่ต้องใช้ครบ รวม compression, PDF/fontkit, pg และ playwright-core
- ตรวจ readiness ผ่าน /api/health ซึ่งมี query ฐานข้อมูล โดยไม่ข้าม Login
- สร้างตารางบริษัท/ปีก่อน foreign key ของเอกสารเวียน รองรับฐานข้อมูลใหม่

วิธีใช้
1. ให้ผู้ใช้ออกจากระบบก่อนอัปเกรด และแตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่
   ตัวอย่าง D:\HealthCheck\Installers\v7.64.68 (ห้ามรันจากใน ZIP)
2. เปิด INSTALL-REPAIR.bat ยืนยัน UAC และดำเนินการในหน้าติดตั้ง
3. หากถามรหัส PostgreSQL administrator ให้กรอกในหน้าติดตั้งตามปกติ
4. เปิดระบบ ตรวจรุ่น v7.64.68 แล้วกด Ctrl+F5
5. เข้าด้วยบัญชีเดิม ตั้งนโยบายตาม Role และทดสอบงานจริง
อย่าแตกทับโฟลเดอร์ Production ด้วยตนเอง; ให้ตัวติดตั้งจัดการสำรอง/อัปเกรด
