HealthCheck v7.65.09 Production Windows Installer
Base: v7.65.08 (source 745ed5e762059301fa198bd5c1f3e060003612fe; installer bc3b37b903265b64b64ad7d09801f89d6686aed5)

1. ช่องค้นหาและปุ่มอยู่แถวเดียวบน Desktop; Tablet จัดหลายแถวโดยไม่ซ่อนฟังก์ชันสำคัญ
2. ปุ่มเดียวสลับ “เปลี่ยนเป็นแบบตาราง” / “เปลี่ยนเป็นแบบเดิม” และจำมุมมองเดิม
3. เพิ่มช่องไฟและแถบผลการค้นหา แสดงจำนวนที่พบและจำนวนที่กำลังแสดง รวมกรณี 0 รายการ
4. ระบบเดิมจำกัดผลค้นหาไว้ 120 รายการและไม่มีตัวควบคุมแบ่งหน้า จึงแสดงช่วง “แสดง 1–120 จาก 125 รายการ” ตาม total จริงจาก PostgreSQL โดยไม่อ้างว่าแสดงครบ
5. แสดงข้อความเรียงตามการปรับปรุงล่าสุดสำหรับผลจาก API และความตรงกับคำค้นสำหรับการค้นหาในเครื่อง
6. ตารางใช้ radio เลือกคนเดียว เปิดรายละเอียดทันที ไม่มีปุ่มทำรายการเหนือรายการหรือซ้ำในแถว
7. ย้าย Export เข้าในรายละเอียด ส่งออกเฉพาะลูกค้าปัจจุบัน โดยยังตรวจสิทธิ์ customerExport
8. A4/HTML: เปลี่ยนชื่อปุ่มเป็น “รีเฟรช” คง “พรีวิว PDF” เพิ่ม “เปิดหน้าลูกค้า” ถัดจาก PDF โดยใช้ record key ปัจจุบันผ่านเส้นทาง staffPreview และสิทธิ์ customerSensitiveView เดิม
9. คงข้อมูล หัวข้อ ฟอร์ม และขั้นตอนทำรายการเดิม ไม่รื้อโครงหน้าลูกค้าหรือรวมฟอร์มข้อมูลส่วนตัวกับแพ็กเกจเพิ่มเติม
10. ยกเลิกผลค้นหาค้างเมื่อผู้ใช้ล้างคำค้น และคงตัวกรอง Booking ในโค้ดค้นหาที่โหลดท้ายสุด

ติดตั้ง: สำรองฐานข้อมูล แตก ZIP ทั้งหมด แล้วเปิด INSTALL-REPAIR.bat ด้วย Run as Administrator
ใช้ workflow เดิม: backup, integrity check, migration, health check และ rollback
ไม่เปลี่ยนการเชื่อมต่อ HIS หรือข้อมูล production ของผู้ใช้
