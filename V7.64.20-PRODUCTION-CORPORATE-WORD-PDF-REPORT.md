# HealthCheck v7.64.20 PRODUCTION — Windows Installer

## Scope
Full installer built from **v7.64.19 PRODUCTION Windows REPAIRED**. Consolidates three Corporate Circular source changes in order: (1) corporate mockup FINAL, (2) column alignment R2, (3) Word-style PDF source patch based on the user-edited Word document.

## Changes
- Annual form shows company, affiliates, coordinators, and employee total as separate visible groups while keeping underlying stored annual section IDs unchanged.
- Company tax ID above address, inline Payor fields, uniform input heights.
- Generated annual PDF main body uses one continuous compact grid (no blue section bands), letterhead with document date/number, payor code/plan on company-name rows, tax ID/address aligned, coordinator name/phone/email, one employee total, and name/price/code in program rows.
- PDF pagination splits at row boundaries for variable-length content; real matrix and appended details still use their dedicated annex pages where appropriate.
- Windows installer from the already repaired v7.64.19 base (preflight checks and GUI error handling preserved).

## Compatibility / caveats
- This package contains **application source and Windows installer scripts**, not a signed EXE or MSI. Run `INSTALL-REPAIR.bat` from an extracted directory as Administrator.
- Extracting the archive is not a production deployment. The installer runs backup/preflight, deploy, migration, server health check. Verify your current database backup before upgrading.
- Existing PDF attachment workflows and stored annual records are intended to be preserved; tests use mocks, not real HIS/Windows/PostgreSQL.
- Runtime dependencies are resolved on the Windows target by existing installer; they are not bundled as node_modules.
- Legacy test cases asserting **blue section bands** are deliberately superseded by the user-approved Word-table format. Their failures are not counted as regressions under the new design, but are listed in QA notes.
- The startup-after-Windows-reboot issue was reported earlier and is **not fixed or verified** by this UI/PDF release.
