# Payor / Agreement code-only copy

Add an independent copy target directly beside the already-visible code in Payor and Agreement overview rows. Clicking the code or its adjacent icon copies only that code, including internal hyphens. The existing right-hand icon still copies the complete code - name value. Location and other compound-field copy behavior are unchanged.

The decorator rebuilds safely when master names load asynchronously. It uses visible text only and escapes names; no data, permission, API, QR, PDF or schema changes. app.html cache-busts the updated script. Included in production Windows installer v7.64.87.

Validation: JavaScript syntax and Chromium clipboard-capture integration for exact code/full-value payloads, internal hyphens, keyboard/mobile, async refresh, escaping, missing names, Location and age copy.
