# HealthCheck v7.63.56 — Navigation Template Picker + A4 Summary Actions

## Changes
- Added `พิมพ์ใบนำทาง` and `พิมพ์เอกสาร` buttons to the A4 summary modal footer.
- Navigation printing no longer silently forces the default template when multiple active navigation templates exist.
- If one active navigation template exists, printing remains one-click.
- If two or more active navigation templates exist, a picker is shown with template name/code and default template preselected.
- `พิมพ์เอกสาร` continues to exclude navigation sheets and opens the existing patient-document picker.
- Updated Document Designer hint text so the default navigation template is described as the preselected choice, not the only print choice.

## Update Center
Package is structured for the existing Production Update Center flow:
`Upload Update -> Preflight Only -> Install Update`.
