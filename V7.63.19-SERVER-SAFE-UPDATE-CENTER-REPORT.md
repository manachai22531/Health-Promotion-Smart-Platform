# v7.63.19 Server Safe Update Center

## Outcome

Production is not stopped until package validation, server prerequisite checks, and both source and database backups have completed successfully.

## New safeguards

- **Preflight Only** runs against the staged ZIP without stopping Production. A successful run leaves the package in `READY` state.
- Package extraction, `robocopy`, `pg_dump`, `psql`, and `npm ci` now have hard timeouts: 3, 10, 5, 2, and 5 minutes respectively.
- Each long-running external command writes a heartbeat status every 10 seconds with elapsed time.
- Preflight verifies `.env`, Production release identity/version, writable update storage, available disk space, `pg_dump`, Node/npm only when dependencies changed, and a PostgreSQL `SELECT 1` probe when there are new migrations.
- `npm ci` is skipped if both `package.json` and `package-lock.json` match the installed Production copy.
- Only migration files absent from the installed Production `migrations` directory are run; when none are new, `psql` is skipped.
- Existing source/database backup and rollback behavior is retained. A failure after source backup restores the saved source and restarts the prior version.

## Server flow

`PREFLIGHT → BACKUP → STOP → DEPLOY → optional npm ci → optional MIGRATE → START → HEALTH → SUCCESS`

`STOP` is reachable only after `PREFLIGHT` and `BACKUP` pass.

## Validation
