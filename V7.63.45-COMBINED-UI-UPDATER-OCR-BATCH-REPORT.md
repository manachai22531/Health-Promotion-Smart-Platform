# v7.63.45 Production — Combined UI / Update Center / OCR Batch

## Included changes
1. **Company page**
   - Keeps the three-column `บริษัท | ปี | Booking` board.
   - Search + Status + Year + Sort + result count fit in one compact row on desktop.
   - Only the `i` button beside **สถานะ** opens a compact legend for year status.

2. **Update Center**
   - `Preflight Only` no longer drops the staged package metadata.
   - `READY` carries `packagePath`, `filename`, `version`, `sha256`, `sizeBytes`, and `releaseNotes`, so `Upload → Preflight → Install` works without uploading the ZIP again.
   - The v7.63.44 exact-PID Stop survival fix remains in place.

3. **EMR / Worklist header**
   - Normalized the global top navigation width/placement so these pages use the same header footprint as other views.

4. **Attendance statistics dashboard**
   - Opening the dashboard now calls `renderDashboardFilters()` before rendering, so company/year dropdowns are populated.
   - Existing `renderAll()` refresh behavior updates the filters when state changes while the dashboard is active.

5. **OCR Document Module**
   - Removed demo patient/lab seed values and hides the sample paper until a real document is selected.
   - File input accepts multiple PDF/JPG/PNG files.
   - Added Batch Upload card, status counters, searchable/filterable document queue and sequential **Run OCR ทั้งหมด**.
   - Selecting a queue item opens it in the existing document preview and Human Review workspace.
   - Queue states: `รอ OCR`, `กำลังประมวลผล`, `รอตรวจสอบ`, `เสร็จสิ้น`, `ล้มเหลว`.
   - Human approval marks the current batch document complete while preserving the existing OCR Review / Export Queue workflow.

## Data safety
- No database schema migration is introduced in this release.
- Production-only runtime lock remains unchanged.
- OCR still requires Human Review/Approval; this release does not auto-write OCR results into core Patient/Lab tables.
