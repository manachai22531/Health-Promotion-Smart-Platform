# HealthCheck v7.64.15 — Production Windows Installer

## Base and changes

- Base: v7.64.14 Production Windows Installer (417 entries).
- Applied source patch: HealthCheck-v7.64.14-WORKLIST-ORDER-PDF-FASTPATH-SOURCE-PATCH.zip.
- Workflow: after confirmation, show patient in left Pending Confirmation panel, NOT Today's Cases; only successful HIS Order advances to the right. Existing VISIT/VN alone does not advance. Cancel order moves it back to left.
- Search page: today's confirmed cases use real confirmation timestamp (with fallback for legacy visitedAt).
- Circular PDF: company-scoped save for existing company/year rather than full 30,000-record state rewrite; previous PDFs remain stored, and a PDF failure is reported separately.
- Retained: one-row customer search, parent/subsidiary data, section 04 and 09, flowing 00–10 PDF layout, Production Only, Windows installer and Update Center.

## Deployment and data safety

- Target: D:\HealthCheck\Production; port 3000; PostgreSQL DB health_check_smart_search.
- The Windows installer uses preflight, source/database backup, deploy, migrations, start, and health check.
- The ZIP does not intentionally contain .env, credentials, local backups, node_modules or a database dump.
- No actions have been performed on the user's machine or production database.
- Use a maintenance window, verify backups, and test the new workflow with safe records before relying on production.

## Known limitations and cautions

- No live Windows install, HIS Order integration, PostgreSQL transaction test or real PDF generation test was executed in this environment.
- Workflow tests use mocked records and specific code checks, not a production end-to-end confirmation.
- Pending cases are day-scoped according to confirmation/cancel timestamps; multi-day carry-over/overnight policies still need design confirmation.
- A failed PDF generation after successful data save can leave the data saved but no new generated PDF; the user-facing message distinguishes this.
- New version has to be installed on Windows; simply downloading it will not alter the running v7.64.14.
