# v7.63.57 — OCR Integrated Workspace / Command Dedupe / A4 Footer

## Scope
This release continues from v7.63.56 and keeps all document category/navigation template, TWAIN scanner, company, dashboard and Update Center fixes already present.

## OCR integration
- Main OCR navigation is now a normal application view (`ocrView`) rather than a direct anchor to `ocr-review-mockup.html`.
- The main shell embeds the protected OCR workspace from `/ocr?embedded=1`, so the browser stays on the Health Check Up Smart Search application URL and the normal global header/session/permissions remain visible.
- Added protected `/ocr` server route.
- Legacy `/ocr-review-mockup.html` redirects to `/ocr` for compatibility.
- Embedded OCR hides its duplicate product title and uses a compact OCR control bar under the global application header.

## OCR command cleanup
- Top controls: Mode, Document, ตั้งค่า OCR, Scan กล้อง, Scan Scanner, ติดตั้ง Scan Agent.
- Removed duplicated top-level `กำหนดพื้นที่อ่าน`, `Export Excel`, and `Upload เอกสาร` buttons.
- Batch upload now has one import action: `+ เพิ่มเอกสาร`.
- OCR actions are named by scope:
  - `OCR เอกสารนี้`
  - `OCR ที่เลือก`
  - `OCR ทั้งหมด`
- `Mark Visible Verified` renamed to `ยืนยันข้อมูล`.
- `OCR Setup / Export` renamed to `ตั้งค่า OCR / Export`.
- Mode and Document selectors are visible only once in the compact OCR control bar; the setup tab shows a summary instead of a second set of selectors.
- `Review Only` suppresses OCR run actions and leaves the fields available for manual review.

## A4 summary footer
- All actions are kept on one horizontal row.
- Button padding/gap is compacted without reducing click height.
- The final Save/Confirm action stays at the end of the row.
- On narrow screens, only the footer action strip scrolls horizontally instead of wrapping to a second line.

## Production / updater compatibility
- `VERSION.txt`, `package.json`, and `package-lock.json` are v7.63.57.
- Package layout remains compatible with Production Update Center (`server.js` and `INSTALL-REPAIR.bat` remain at package root).
- Existing runtime `data` preservation behavior from prior releases remains unchanged.
