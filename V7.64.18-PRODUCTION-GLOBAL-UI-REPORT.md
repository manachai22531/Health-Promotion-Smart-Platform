## Safe installation
1. Backup DB and `D:\HealthCheck\Production` with a tested recovery plan; schedule maintenance.
2. Extract ZIP to a NEW directory (not over the running installation).
3. Right-click `INSTALL-REPAIR.bat` and choose **Run as administrator**.
4. Verify `http://127.0.0.1:3000/api/version` returns `v7.64.18`, then test Worklist, A4 dialog, PDF printing and Booking with dummy data.
5. Use topbar **ขนาด UI** selector. If screen looks too dense, choose **ปกติ** to restore original layout instantly.
6. Avoid the older Update Center route if currently running a version with unresolved upgrade reliability; use the Windows installer in a controlled maintenance window.
